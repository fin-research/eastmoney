# 原版可视化图片报告契约

用户明确要求：HTML 指原市场点评可视化图片版，必须与原来一致，禁止自行修改；文字版直接在回复中输出。

## 唯一视觉实现

`assets/market-report.js` 与 `assets/market-report.css` 是从原 Dashboard 市场点评直接编译的自包含资源，含 Svelte、ECharts SVG renderer、原组件和原样式。`scripts/visual.mjs` 只负责把这些资源和同一份报告 JSON 内嵌到单个 HTML，不另建视觉实现。

保留原 `App.svelte` 的可视化 DOM、`.page-shell`、`#report-surface`、`.visual-report-view`，以及 `.is-export-capture` 导出状态。今日聚焦采用原只读显示分支；远端刷新、编辑、AI生成与归档控件不进入图片画布。标题保持“资金管理部 · 市场点评”，日期与星期使用原格式。

必须保留：

- 顶部六张核心指标卡，原图标、数值、涨跌色与详情。
- 01今日聚焦、02公开市场操作、03固收市场、04权益市场、05一级发行、06二级行情、07东财债券。
- 公开市场操作柱图、国债收益率曲线、权益指数仪表盘、申万一级行业矩形树图、一级发行表、原可比债期限列表、东财估值/成交/Bid/Ofr期限结构及汇总。
- 原桌面四列两行布局，权益跨右侧两行；原移动端01—07顺序、原断点与尺寸。不能套其他报告的1080px/A4模板，不能指定新固定画布替代原视口布局。
- 原 `styles.css`、编译后的 `app.css` 和组件样式；原 `deriveReport`、view-model及图表配置。缺失数据、涨跌方向、报价与离群筛选沿用这些实现。

禁止自行改变布局、颜色、字体、字号、模块顺序、图形类型、标签和尺寸；禁止用文字网页、手写SVG、图片生成模型或重新设计的卡片替代。禁止添加来源区、解释小字、审计标签、表格附录、新页脚或装饰。审计信息留在 JSON 文件，不进入原画布。

## 验证

每次调整视觉打包时，以同份规范数据、同视口、同 `.is-export-capture` 状态对照原 App。实际浏览器检查指标、七区位置、图表、文字换行、空值、日期、涨跌色和完整画布；源码检查或单元测试不能代替视觉对照。检查浏览器实际 SVG 图表已出现，且离线文件不请求 CDN、字体、API或其他文件。
