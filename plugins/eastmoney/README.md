# eastmoney 插件

- MCP：`eastmoney`（https://eastmoney.hasbai.xyz/mcp，OAuth，首次使用运行 `/mcp` 授权）
- 技能：market-commentary（含今日聚焦）、secondary-pool-weekly、research-commentary、interbank-ledger（拆借台账：ZIP 归档、资金系统导入与草稿、流程截图）
- 依赖：Node.js 20+（报告脚本）；interbank-ledger 另需 macOS、Playwright 和办公网络，凭据见其 SKILL.md
- 安装：`/plugin install eastmoney --marketplace fin-research/eastmoney`
