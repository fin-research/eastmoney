# 竖版可视化报告（ImageGen 专用）

当用户提供报告/PDF/完整文字稿，并要求“生成图片”“图片版报告”“可视化报告”“竖版长图”或“信息长图”时，执行本技能，以 ImageGen 生成竖版图片。市场收盘点评、股债复盘的 HTML 或原版可视化图片报告使用 [market-commentary](../market-commentary/SKILL.md)；二级池周报使用 [secondary-pool-weekly](../secondary-pool-weekly/SKILL.md)。**首要交付物是 ImageGen 生成的最终图片，而不是文字快评、HTML 页面、PPT 或程序绘制的图表。**

## 不可违反的规则

1. **唯一出图方式：调用宿主提供的 ImageGen 图片生成/编辑工具（如 `image_gen.imagegen`）生成完整最终画面。** 不得用 Python、Matplotlib、Plotly、PIL、SVG、HTML/CSS、Canvas、D3、Mermaid、PPT、PDF 绘制、排版、拼接、覆字或转换生成最终图像，也不得以图表工具绘图再截图冒充 ImageGen。代码仅可用于**读取、清洗、核对、计算数据**，不得用于绘制或修改最终图片。
2. **准许并鼓励主动查找数据。** 报告所需历史走势、指标对比、市场数据若未附在原稿中，应先联网或通过可用的数据/研报工具查找真实序列，核实后再交给 ImageGen 表达。不得因“原文未给历史序列”就直接取消图表；检索无果才以政策前后对比、矩阵或传导图代替。
3. **绝不捏造数值。** 历史曲线每个关键数值、起止日期、口径和量纲必须有可追溯依据；不得使用模型臆造的趋势线、随手填补的数据、未经证实的收益率或利差。与原稿有口径冲突时优先保留原稿并明确差异，不得悄然替换。
4. **遵从用户最终稿。** 保留原文的标题、核心判断、因果关系、关键数字和结论；为可视化可压缩文字，但不得改变原意。稿件没有“应对建议”就不自行增加；有则精简呈现，不必放大投资建议。补充的外部数据属于背景证据，不得擅自变成新观点。
5. **不要向用户输出绘图代码或 HTML。** 可展示最终 ImageGen 图片与极简数据来源说明。若 ImageGen 当前不可用，应直接说明无法按要求出图，不得偷偷切换其他绘图方式。

## 工作流

### 1. 提炼报告

- 阅读全文（包括表格与第二页），抓取事件名称、发布日期、快评时间、3—5 个核心结论、所有重要数字、市场影响及需对比的政策工具。
- 根据稿件识别**最值得图示的证据**：资金利率与政策利率、国债收益率、期限/信用利差、CPI/PPI/PMI、政策规模、政策工具差异等；按相关性取舍，不因模板硬凑。

### 2. 主动检索并核对数据

- 先使用用户提供的数据与报告；若历史图表能明显提高表达效果，主动搜索权威数据源：央行、国家统计局、财政部、外汇交易中心、交易所、FRED 或具有明确数据口径的公开研究资料，以及已连接的专业数据库或研报检索工具。
- 优先采用同一来源、同一统计口径的连续时间序列。记录指标、频率、起止日期、单位、数据来源和最后一个观察值；报告中的政策利率也要核对生效日期。
- 原文数值与外部序列冲突时不混绘不同口径；不把季度均值画成月度点，不把利差与收益率用同一轴，不把预测值伪装为实际值。
- 将证据整理为精确的 **ImageGen 数据约束表**，包括曲线若干真实采样点或每期完整数列、图例及最近读数。不要只给模糊的“总体向下”指令。
- 如未检索到可靠历史序列，允许只做真实的当期/前值对比、可验证的政策利率对照、工具对比和传导链；不得凭空绘出“历史走势图”。

### 3. 信息设计：优先参考首版金融长图

- **视觉风格**：券商研究报告级、紧凑精致、蓝白主色、深海军蓝标题/栏头、橙红色强调、少量蓝色渐变和清晰图标；可使用金融建筑视觉作为简洁题头，但不能挤占图表面积。
- **画幅**：默认单张竖版长图，宽高比约 2:3 至 9:16，适合手机浏览、分享和正式报告。层次清楚、留白适中、信息密度高，不要简化成四张大色块或营销海报。
- **推荐结构**：紧凑标题/日期/来源 → 一行核心判断与 3—4 张要点卡 → 3—4 个带编号分析模块；中部主要空间（约 45%—60%）留给真实折线图、利率对比图、工具对比表和政策传导图 → 最后用简短尾部风险或展望收束。
- **视觉重点**：优先展示真实历史曲线（通常 2—3 张）、利率数字对比（例如 15BP）、新旧工具对照表、债市与权益市场的双通道传导。金融专业图表的坐标轴、日期、单位、图例和结论数字必须清晰。
- **文字控制**：标题与关键结论可大字，正文尽量不超过每模块 2—3 条短句；原则上避免原文整段复制。内容多时优先保留图表、结论和关键条件，压缩修饰语。
- 不要求照搬固定模板，事件是宏观数据则更多真实趋势，政策改革则更多政策前后对比与影响传导。

### 4. 仅通过 ImageGen 生成最终图片

- 将报告事实、不可更改的中文词句、关键数据约束、明确来源、图表类型、模块结构、色彩、长图尺寸和中文准确性要求组合成**一次完整的图片生成请求**，直接调用 `image_gen`。
- 提示词中强调：**不得补造日期、利率水平、图表数据、图例和单位；禁止替换简体中文专有名词；画中数字必须与经过核验的数据一致。**
- 绘制历史数据时，向模型提供可核验的采样点、准确起止日期及末值；若其生成的点位和数据有明显偏差，须重新调用 ImageGen 调整，而不是用程序涂改。
- 不使用其他程序出图，不将生成后的图片另行添加文字、图例或曲线；修正同样交给 ImageGen。

### 5. 交付前核验

核对：① 事件标题/日期/部门 ② 数字与百分点/BP/亿元单位 ③ 走势方向与末值 ④ 工具的支持对象和用途 ⑤ 是否添加了原稿没有的建议 ⑥ 图表来源和图例是否可辨 ⑦ 无错别字、乱码或不实背景数据。错误明显则要求 ImageGen 重画相关画面。无法确保精度时删减不可靠曲线，改为真实数字卡或明确标为“示意”的传导图，**不可假称逐点精确**。

最终直接展示 ImageGen 生成的图片；如额外使用了外部数据，附一句简短来源/统计截至日期即可，不写长篇制作说明。
