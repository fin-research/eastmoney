# 债券利率与发行择时研究

## 目标与当前边界

发行人的目标是，在给定最迟发行日之前控制**实际融资利率及等待风险**。原逐笔模型的“相对同类近 30 日可比债发行利差偏离”只描述发行定价。不能替代无风险利率、信用利差和发行时点的联合预测。当前默认入口与线上推理已迁移至绝对票面、净节约及TreeSHAP契约，旧路径不再作为当前结果源。

`main.py --rate-research` 是现有 CLI 的研究模式，复用统一特征注册表。只读取本地报价，不更新 Choice、不上传生产表。研究产物及当次结论在忽略的 `outputs/rate-research/`、`.Codex/rate-research/`，不得提交数据、模型或生成报告。

```bash
uv run python main.py --rate-research --research-output outputs/rate-research/development-daily
uv run python -m unittest discover -s tests -p test_rate_research.py -v
```

## 信息集与标签

- 决策时点为 T 日开盘前，特征仅使用严格早于 T 的最新完整报价。
- `h=0` 预测 T 日收盘收益率相对前一完整报价的变化。`h=1..30` 是自然日，到期落在休市日时，目标为窗口内最后报价日。
- 标签单位统一为 bp，绝对收益率百分数为 `level_bp / 100`。尾部尚未成熟的窗口不生成标签。长假保留起点并记录报价年龄，不删除长假相关行情。
- 当前独立目标为 3Y 国债、3Y AAA 企业债收益率、二者信用利差。企业债二级收益率只是市场融资环境代理，不是证券公司一级发行票面。5Y/发行人/次级条款需要独立的定价校准与验收。
- 日历暂以历史真实报价日期评价。未来可执行发行日必须使用有来源和覆盖年份检查的交易所日历，不得仅筛周一至周五。
- 特征包括统一资金面、曲线、信用利差、日历，以及报价日收益率变化、相对均线偏离和变化波动。市场水平用百分数，新增变化特征用 bp。未经确认发布日期与历史版本的宏观、公司数据暂不进入利率候选。

## 模型与调参

候选由 `model/rate_forecast.py` 显式注册：随机游走、历史漂移、不同正则化和历史长度的 Ridge、浅层 LightGBM、向随机游走收缩的模型、短期预测饱和后可选漂移延伸。分解候选将同起点同终点的国债与信用利差预测相加。不能混用实际未来分量。

研究每轮必须记录所有候选，不能只保存最好的一次。开发入口只用 2022—2025 年比较目标、特征、模型、历史长度与策略参数。是否已有留出期被观察，以冻结协议和实验记录为准，不能仅凭按年份切分就宣称独立测试。候选固定树数，不用外层评分集早停。若增加调参，早停与参数搜索只能在训练窗口内部、按标签成熟时间再次隔离。

## 验证与策略

2019 年起的历史作训练，2022—2025 年逐季度扩展窗口评分。每个训练标签终点必须严格早于测试季度首日，不只是训练行日期早于首日。Ridge 的缺失填充和缩放器仅在该折训练样本上拟合。每条预测保留起点、源日期、目标终点、训练标签最后日期、样本数、候选与季度。

验收同时看：

1. 各期限、各年度 MAE/RMSE、相对随机游走改善、方向及偏差。国债和信用利差分开检查。
2. 固定起点选择发行日：只凭起点预测选择，未来实际收益率仅用于评分。
3. 每天重新判断的停止策略：当天预测决定继续等待或发行，到最迟日期强制执行。不能先看完整真实行情再选最低日。
4. 与立即发行、固定截止日发行比较，报告实际收益率代理的差额、等待比例、后悔成本及最差年份。
5. 对重叠起点使用保留连续性的 moving-block bootstrap，并同时报告固定规则取样的非重叠窗口结果。开发期区间不消除模型选择偏差。

`model/rate_policy.py` 支持每次看下一报价日或剩余窗口的滚动停止策略。缺预测的起点保留明确状态，不能默默缩小分母。所有评价仍是市场代理效果，不能直接乘发行规模宣传为已经实现的公司节约。

`model/rate_intervals.py` 使用同一候选、同一期限最近 252 条已成熟样本外残差校准 90% 等尾区间，至少需要 120 条。每个起点只允许 `label_end < origin` 的残差。“比当日发行便宜”的概率使用同一历史起点的未来日与当日**成对残差差**，不假设不同期限误差相互独立。区间名称不能替代真实覆盖率、宽度与状态变化检查。缺少校准样本时明确不提供区间。

打开留出结果之前，应在忽略目录保存不可覆盖的冻结协议：代码版本及校验值、源数据校验值、候选、决策规则、区间规则和评价区间。冻结检验失败或改善主要来自简单基准时，保留失败证据。此后如继续利用该年份优化，它已是研究参考集。不能再称为新的独立封存测试。

## 一级发行票面定价

```bash
# 使用已落地的发行资料，默认不消耗外部额度
uv run python main.py --primary-research --research-output outputs/rate-research/primary-pricing
# 显式补取日期、发行时评级、最终票面；成功批次原子保存，可断点继续
uv run python main.py --primary-research --refresh-pricing-metadata --research-output outputs/rate-research/primary-pricing
```

- `data/primary_pricing.py` 只研究 SH/SZ 交易所 1—10 年固定利率、无含权条款的证券公司债及次级债。未知条款不混入标准发行方案。原始工作簿不修改，也不要求本目标用不到的“发行利差”必须有值。
- `TENDERDATE` 是记录的招投标/簿记日，`ISSUE_DATE` 是原报表选取的发行起始日。二者不强制相同。定价晚于发行起始的可疑记录先隔离，待原始公告核实。无有效定价日期的行明确排除，不拿发行日或公告日伪装成已知簿记日。`TENDERBIDDINGDATE` 返回时段，不能把它解析为日期。
- 输入使用严格早于定价日的市场报价。标签是 `TENDERFINALCOUPON` 最终票面。用定价日的 AAA 企业债 3Y 二级收益率分解发行溢价，这个当日价格只出现在标签中，不得进入当日信息集。历史标签直到定价日、发行起始日都过去后才可供后续估计使用。
- 评级使用 `ISSCORPCREDITRAT` 发行时主体评级，并统计它与原快照评级的差异。发行时评级仍依赖供应商历史字段，不等于已具备所有输入的逐日原始版本。
- `model/primary_pricing.py` 比较二级市场基准、同类型/评级/期限可比债、发行人自身历史溢价、向同类样本收缩、相对同类的发行人偏离，以及上一笔实际票面。面向默认发行人的研究候选为自身溢价的 90 自然日半衰期加权中位数。冷启动回退同类，缺乏同类样本则不生成该估计。参数来源必须能回溯到开发结果，并单独检查目标发行人表现。不能只按全市场平均数选择。
- 历史仅保留最近 730 天。同发行人同日同方案的多只债聚合为一个观察。有效样本数用日期权重计算，不能将发行规模当独立样本量。
- 逐发行时点评分，不使用尚未成熟或同日其他发行结果。比较 MAE/RMSE 时使用共同可比较样本。保留全部覆盖数、未估计数及分年度结果，不得删除困难发行来改善成绩。
- 当前 3Y/5Y 普通债和次级债候选报价写入 `primary-current.csv`，选定方案写入独立本地 `primary-assessment.json`。这只是当前票面定价研究，不替代生产结构化输出或声称已接通未来 30 天择时。市场报价实际日期和自然日年龄随结果返回。
- 90% 历史误差区间只用定价前已成熟的样本外残差，按同评级/期限/类型校准，至少 30 个发行观察，最多最近 252 个。缺少样本时不编造区间。用 `primary-intervals.csv` 检查历史覆盖和宽度，不能仅因区间存在就称为可信。

## 当前至未来N天的本地发行预测

发行事件的完整回放、发行日纠错、逐笔30个预测时点和实际等待规则检验见[ISSUANCE_BACKTEST](ISSUANCE_BACKTEST.md)。当前下行路径不能视为已建立择时优势。重点报告我司样本、恒下行方向基准和没有等待触发时的未定义胜率。

默认入口位于同一 `main.py` / `pipeline.py`，`--issuance-forecast` 仅为同一路径的显式别名。新入口生成实际票面预测，不把旧相对发行利差字段改名伪装成票面。

```bash
# 当前及未来30个自然日，默认3Y AAA普通证券公司债、30亿元
uv run python main.py --issuance-forecast --window-days 30
# 自定义期限及等待成本；等待成本为每天的年化票面等价bp
uv run python main.py --issuance-forecast --window-days 10 --tenor 5 --waiting-cost-bp-day 0.1
# 完全重放已固定的数据，不读取数据库
uv run python main.py --issuance-forecast --as-of 2026-09-21 --input-snapshot outputs/issuance_forecast/inputs.json
```

- 输出在 `outputs/issuance_forecast/`：`issuance_forecast.json`、`report.md`、`forecast.csv`，以及按日期/市场模型区分的 `evidence/`。`--forecast-output` 可更换目录。
- N 为从当前日到最迟发行日的自然日差，支持 1—30。JSON 同时给出 N+1 个日历日的市场路径，以及其中可发行日期的票面、区间、等待成本与成本比较。非报价日明确标记沿用前值。调休工作日可能有利率报价，但不是交易所发行日。
- 日历采用已核对的 2026 年交易所休市与调休工作日规则。未知年份明确报错，不猜测节假日。最新行情必须覆盖模型日期前一个报价工作日。过期输入拒绝提供发行建议。
- 默认通过只读repeatable-read事务读取Neon资金和发行定价数据并保存快照。历史特征从2019年起统一计算，含权0/1和代码大小写统一规范，不调用Choice或改写Excel。研究回放允许显式资金快照与本地资料组合。其尾部拼接仍核对最近60日关键利率，不与生产输入混为一套历史版本。
- 默认市场模型为 `lgb_anchor_drift`。完整交易所票面开发期逐期限等权MAE及配对成本误差支持该选择。固定权重组合、漂移、不变利率仍是研究基准。LightGBM采用120棵树、7叶、深度3、学习率0.025、最小叶样本80、L1=1/L2=20、列采样0.8，参数固定后按成熟标签训练。不能因某个已观察年份胜出就反向选择默认模型。
- 多期限检验逐笔固定发行方案，预测时点为定价日前 h 个自然日，h=0..30。市场时钟取该时点之后首个报价日，含银行调休工作日。最终票面作结果变量。训练标签的整个日历窗口截止及观测终点均须早于预测时点。不得因未来追加数据而提前将假期尾部视作成熟。
- 根据同评级、期限、类型的多期限最终票面误差，直接估计票面区间。按发行人/日期聚合，保留同一历史记录的市场与发行人误差关系。至少 30 个成熟观察，最多最近 252 个。市场波动缩放仅作为可比较研究选项。不能只因某个已观察年份改善就替换默认方法。
- 等待成本比较使用同发行人两次连续发行、间隔不超过 30 日的实际票面差，构造联合误差。校准池合并相同评级/期限/类型，并非均为目标发行人。使用 1—5、6—10、11—20、21—30 日期限组，至少 20 对。缺少配对样本时不给可靠胜率。
- 等待建议同时要求预期净节约至少 2bp、经验省钱概率至少80%、净节约10%分位为正。否则不强制等待最低预期日期。该规则提供成本角度的参考，未评估审批、额度或公司流动性。最迟日期和等待成本由输入明确约束。
- 年度费用换算：`bp × 发行规模(亿元) = 万元/年`。它是模型预期差额，不是已经实现的收益。不同债券期限不能仅按票面高低排序。
- 每次生成可追溯的代码/输入及预测哈希。证据缓存只在内容和算法签名一致时复用。所有历史样本的市场来源、市场训练标签和发行结果都必须早于对应预测时点。2026 年已被观察，后续评价只作为历史研究参考。

## SHAP与发布

TreeSHAP使用实际LightGBM树的路径依赖解释。`base_coupon_bp`包含当前市场锚、发行人溢价、期限漂移与树期望值。加上全部`features[].shap_bp`等于`prediction_coupon_bp`。因子贡献解释模型而非因果，不给漂移或一级溢价伪造SHAP。

新工作台契约为`issuance-forecast-v1`，详细发布步骤见[ONLINE_INFERENCE](ONLINE_INFERENCE.md)。只允许通过特征/预测/TreeSHAP/业务字段一致性核验的模型包激活。历史记录和人工内容保留。数据库不存原始结果JSON。

方法参考：[scikit-learn 时序滞后特征与隔离验证](https://scikit-learn.org/stable/auto_examples/applications/plot_time_series_lagged_features.html)、[Diebold 与 Li 的收益率曲线动态预测研究](https://www.nber.org/papers/w10048)。前者支持按时间与信息集划分验证。后者支持把曲线动态作为独立预测问题，不构成中国债市短期模型有效性的证据。
