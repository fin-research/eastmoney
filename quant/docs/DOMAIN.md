# Domain Rules

本文只记录会影响实现正确性的稳定业务口径。当前模型清单、特征名和实验结果分别以代码及 当前 [README.md](../README.md) 为准。

## 债券融资择时

- 唯一监督目标是实际最终发行票面。一个统一模型接收发行人、评级、期限、普通/次级、公募/私募、规模及提前期，新短预测只支持T+1、T+14、T+30自然日。分类未知不默认AAA或公募。新主体允许历史特征缺失，预测可执行不代表已验证其精度。
- 经济基准残差研究仍还原实际票面：`industry_excess`扣起点同期限AAA行业曲线，缺节点或超范围回退国债。AAA曲线是行业参考，评级、次级和方式增量由同一模型估计。`primary_residual`扣国债加加权分层一级溢价，依次回退同类均值和零溢价。`industry_basis_residual`进一步以当前行业曲线加历史行业相对发行basis作锚，历史节点缺失不混入国债相对溢价。

  当前或basis缺失整行回退原国债加一级路径。训练、预测和贡献解释须使用同一固定基准。改变同起点固定基准本身不会创造等待收益，票面精度和选日效果分开验收。
- 一级事件限SH/SZ、当期重新确定票面、固定利率、1—10年普通/次级证券公司新券。定价日缺失、冲突或晚于发行起始日的记录不进入正式评价。结构证据确认沿用原票面的续发不进入训练和主评价，疑似续发未核实的单列隔离，原始记录保留。不得按误差剔除真实新券。发行范围由协议和 manifest 固定。当前公募包只包含明确公募，旧全范围共同训练仅用于历史复核。
- 市场和已知发行信息严格早于预测日，训练标签须在月初重训截止前可用。每笔事件在不同提前期展开后的总权重为1。没有历史条款公告版本时，回放称“给定发行条件的预测”，不声称当时已知最终方案。
- 二级存续债估值是输入，不能充作每日真实票面标签。目前按实际返回的余额、估值、剩余期限汇总，不能把该覆盖称为完整存续债池。未经历史可用时点核验的宏观/财务变量不进入核心效果结论。
- 发行人期限报价的OLS只使用正余额且收益率、期限均完整的券。斜率、截距与期限边界使用同一组有效记录；不可估计仍为空，不外推。`fit_observations`只用于覆盖审计，不进入模型。旧余额加权字段和原缺失计数保留既有语义。
- 候选含平方误差条件均值、L1条件中位数和Huber稳健中心。当前公募生产包为显式授权的Huber点预测，不支持预期节约字段。中位数与稳健中心之差不得导出为预期节约。所有目标表达均还原为真实票面，按开发票面MAE及完整保护门槛选模，胜率不参与训练或选择。所有年份和负面结果保留。
- 新短预测直接学习实际票面，不拼接固定估值锚，不设方向标签、跌幅阈值、系数符号或输出修正。训练窗口、插补及模型结构事前固定。报价可作为输入，系数由训练估计；固定估值加回仅用于独立比较。
- 新短预测不套用最低四分位或最小值建议规则。输出“仅预测票面”，推荐日期和节约字段为空。三个自然日预测点不表示可发行日期。旧研究规则只用于原来源复现。未知年份日历和过期行情拒绝预测。

### 报告口径

- 原UI、业务指标、四方案对比、卖方观点和人工记录全部保留。四方案调用同一个模型。市场参考路径不伪装成另一个市场预测模型。
- 票面使用百分数，误差和贡献使用bp。模型基准加全部贡献还原预测。树贡献或线性贡献均属归因，不解释为因果。市场分离结构用`additive_market_coupon`标记组合归因，经济锚以训练时冻结的国债/信用参考中位数分解，不能冒称纯TreeSHAP。
- 新研究分别报告提前1、14、30日，每个提前期每笔发行一次。展示MAE、RMSE、实际减预测的平均偏差、样本数及排除数。
- 预测命中率为真实票面与预测票面的绝对误差不超过5bp的比例，高估和低估对称判定，字段为`hit_rate_5bp`。固定阈值不参与选模，不调整至预期百分比范围。新结果`win_rate`为空。历史单侧sigma胜率保留原归档，不能改名为命中率。误差标准差仅为诊断。
- 历史结果均为研究证据，已反复观察的2026不称独立封存验证。不将代理选日结果改名为一级发行胜率，也不为无真实发行日虚构结果。
- 训练集内、历年时间外开发、最终评价分别报告，训练和最终指标不参与选模。偏差以实际减预测计，负值表示整体高估。不能从最终评价残差直接估计校准。不同月训练集事件重叠，训练样本数不得跨月累加。
- 沿用`issuance-forecast-v1`，直接更换预测核心和必要字段。旧原始归档和人工记录保留，旧结果不迁移、不重算，不新增平行版本或双读。
- 卖方观点由Dashboard独立生成。Quant不调用研究库拼接观点。
