# 行业曲线短期延续预测

对象是 AAA 证券公司债 3 年期行业曲线。最近报价为 i，决策日 T 是 i 的下一个报价日。模型只用 i 及之前的信息预测：

- `catch_up`：T 日报价减 i 日报价，即最近报价尚未体现的变动。
- `wait_w`：T 之后第 w 个报价减 T 日报价。负值表示等待更便宜，正值表示 T 日发行更便宜。

信号规则：`wait_3` 预测大于 +0.5bp 为“尽快”，小于 −0.5bp 为“暂缓”，其余“等待”。实现在 `model/timing_nowcast.py`，复算命令 `uv run python scripts/timing_nowcast_validation.py --output reports/timing-nowcast.json`（只读 Neon，不训练线上包，不取 Choice）。聚合结果在 `reports/timing-nowcast.json`。

## 为什么可预测

行业曲线是平滑的估值曲线。2019 年以来日变化一阶自相关 0.40，国开 3 年和国债 3 年为 0.19、0.18。它跟随国债、国开、AAA 企业债的变动并滞后，所以最近流动性曲线的变动，会在随后几个报价日继续反映到行业曲线上。特征是行业曲线 0—4 日滞后、国开 3 年、国债 1/3/10 年、AAA 企业债 3 年的 0—3 日滞后和 DR007 的 0—1 日滞后的日变化，固定 alpha 的岭回归，每月重估，只用窗口已结束的样本。

## 样本外结果（2021 年 1 月起逐月滚动）

|预测量|起点|相关|R²（对比不变）|平均绝对误差 bp（不变→模型）|各年相关（2021→2026）|
|---|---:|---:|---:|---|---|
|catch_up|1433|0.465|0.219|1.50→1.35|0.38 0.53 0.50 0.45 0.38 0.27|
|wait_1|1432|0.168|0.020|1.50→1.49|0.09 0.28 0.12 0.10 0.12 0.03|
|wait_3|1430|0.124|−0.006|3.37→3.33|0.16 0.19 0.11 −0.01 0.11 0.13|

只用行业曲线自身滞后时，`catch_up` 的相关为 0.34，R² 0.12；加入流动性曲线后升到 0.47、0.22。

`wait_3`、阈值 0.5bp 的信号（bp）：

|信号|次数|等待实现收益|
|---|---:|---:|
|暂缓（预测等待更便宜）|633|省 0.94|
|尽快（预测等待更贵）|324|多花 0.73|
|无条件|全部|省 0.42|

检验信号区分力用差值：暂缓信号日的等待收益减尽快信号日的等待收益，不依赖 2021—2026 年收益率整体下行带来的基准（等待平均省 0.42bp）。`wait_3` 为 1.68bp，对整张表做移动块（10 个起点）自助的 95% 区间为 [0.71, 2.84]。等待 1、2、3、5 个报价日与阈值 0.3、0.5、1.0 共 12 个组合的差值都为正，区间下限都大于 0（最小 0.37，等待 5 个报价日、阈值 0.3），见 `reports/timing-nowcast.json`。不再单独报告两侧各自的显著性。等待 3 个报价日和 0.5bp 阈值是看到这些结果后选定的，不是事前登记。

## 与此前研究对比

- 此前 `short_signal_validation` 修正后的 LightGBM 短期选日，2014—2025 年 AAA 企业债 3 年，相对立即发行平均改善 0.63bp，相对固定等待 1 个报价日改善 0.47bp（Holm 显著），相对固定等待 3、5 个报价日不显著；`structural-timing` 的 13 个结构候选没有一个通过 Holm 校正（最小调整 p 为 0.056）。本研究的量级一致，约 0.5—1bp，同样集中在 1—5 个报价日。
- 此前研究的对象是选日的实现成本，本研究直接预测行业曲线 `catch_up` 与等待收益，并提供 R²，所以能区分“曲线滞后”与“方向”。

## 与实际发行票面的关系

样本是 2021 年以来712笔公募固息、无选择权的证券公司债和次级债，期限 1—10 年，每笔取同期限的行业曲线点。票面偏差为票面减前一报价日曲线，再减该发行人（同债种）此前最近 5 笔偏差的中位数，剩余偏差平均绝对值 6.2bp。区间按连续 10 个定价日整块重抽样。

|解释量|斜率|95% 区间|
|---|---:|---|
|T 日实际的曲线变动|0.99|[0.64, 1.32]|
|`catch_up` 预测|1.41|[0.75, 2.16]|

票面与 T 日曲线变动一比一同向，`catch_up` 预测也传导到票面。用前一报价预测偏差的平均绝对误差为 6.20bp，加上 `catch_up` 后为 6.07bp。斜率是同向关系，因果方向未检验，估值曲线也可能参考新发行价格。

## 按实际发行日回测信号

对上述发行，用定价日前一报价的 `wait_3` 预测决定：预测小于 −0.5bp（暂缓）就等 3 个报价日，否则按实际日期发行。等待的收益取该债自身期限的曲线变动，成立的前提是票面与曲线一比一同向（上表）。这是反事实，不是同一发行人 3 个报价日后的真实票面。

|项目|结果|
|---|---|
|暂缓信号发行数 / 等待 3 日平均省|257 / 1.30bp|
|尽快信号发行数 / 等待 3 日平均省|193 / -1.63bp（即多花）|
|两者差值|2.93bp，95% 区间 [0.72, 5.64]|
|按信号执行，每笔平均省|0.47bp，95% 区间 [0.15, 0.81]|
|总是等 3 日，每笔平均省|0.21bp|
|712笔合计节约利息（按金额、期限，未折现）|约 1.9 亿元|

## 与线上包对比

两个模型都只用标签截止 2025 年末的样本拟合，在同一批起点、同一结果上按模型分数分三档，比较最低档与最高档的等待收益差（bp）和 Spearman。

|结果|期间|起点|新模型 Spearman / 档差|线上包 Spearman / 档差|
|---|---|---:|---|---|
|决策日后等 3 个报价日|训练期 2021—2025（两者都是样本内）|1249|0.20 / 2.22|0.23 / 2.67|
|决策日后等 3 个报价日|测试期 2026（两者样本外）|201|0.15 / 0.68|0.13 / 0.06|
|30 日窗口平均（线上包的标签口径）|训练期 2021—2025（两者都是样本内）|1249|0.12 / 2.39|0.19 / 4.07|
|30 日窗口平均（线上包的标签口径）|测试期 2026（两者样本外）|185|0.27 / 1.19|0.05 / -0.08|

训练期线上包更好：它有 140 维特征和 290 个参数，拟合训练期更充分。测试期新模型更好，线上包在 30 日窗口上几乎没有区分力。训练期强、测试期弱是过拟合的典型形态。

测试期证据有限：2026 年只有 201 和 185 个起点，互不重叠的窗口很少，没有显著性检验，两者在等 3 个报价日上的 Spearman 接近（0.15 对 0.13）。新模型的特征集、岭回归系数、等待 3 个报价日和 0.5bp 阈值是看过包含 2026 年的数据后选定的，不是事前登记；线上包在 2026 年之前就已确定，其 2026 年数字是更干净的样本外检验。所以 2026 年的对比支持新模型不弱于线上包，不能证明它更好。

逐月滚动的新模型在 2021—2026 年全部起点上都是样本外预测，对应的对比见 `reports/timing-nowcast.json` 的 `versus_deployed`，其中线上包在 2026 年之前是样本内，不能比较。
