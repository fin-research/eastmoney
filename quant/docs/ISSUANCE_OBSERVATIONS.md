# 发行资料观察时间切片

当前是独立只读协议接入，不构建训练面板，不替换历史输入，也不接入生产 Workflow。Data 写入协议唯一见 [发行观察](../../data/docs/modules/issuance-observations.md)。首次公开时间仍未知，完整评级、条款版本和全池后续修订仍未覆盖。给定最终发行条件的旧回放不能据此改称事前研究。

## 职责

- `online/observation-store.mjs` 只捕获已有 R2 adapter 的 `get/list`，限制指定实例及 Data 自有前缀，逐页、逐对象和累计限制读取。它不提供写入、删除、任意路径或上游查询能力。实际运行绑定由调用方另行验收。
- `online/observation-contract.mjs` 校验 schema v1 有限来源、规范请求及键、原发行日上下文、内容字节 SHA 和质量记录。采用同一 JavaScript 规范化语言。共享测试样例由 Data 所有方生成并自行核验，不用 Python JSON 重新编码内容哈希。
- `online/observation-slice.mjs` 显式接收 `instances`、带时区的 `cutoff` 及可选的原发行日 `bonds`。输出有限字段观察、原始状态、逐项来源、请求与字段覆盖、排除原因及实际读取元数据。不拼训练标签，不读取数据库当前行。

## 截止与选择

实际收到响应、请求映射的 R2 `uploaded`、内容对象的 R2 `uploaded` 必须严格早于截止时刻。客户端 `archived_at` 只用于来源审计，不能替代真正持久化时间。R2 字节、服务端上传时刻、ETag、版本和大小均保留。对象在列举与读取之间变化时拒绝该观察。

请求集合只有在 manifest 本身也已于截止前持久化、记录和来源/结果逐项一致时才可称有限范围完整。缺失、损坏或晚到的 manifest 保持 unknown，不从事后清单补写过去的完整覆盖。声明归档失败、记录或内容不可用均保留缺口。Completed、读取成功或空数组不等于模型覆盖完成。

同来源、代码和字段按实际响应接收时间选择最新观察。后续 absent/null/empty、缺券、来源失败和隔离状态不回退到旧非空值。同刻同状态/值/上下文合并出处。同刻更正或上下文冲突标为 ambiguous。公告日保留为原始字段，不变为最终票面首次发布时间。原发行日与调用方期待的发行日不一致时标明冲突，未知发行日不补造。

请求映射已验证但内容不可用时，保留有限上下文的不可用状态。CTR失败、无数据、空表或遗漏先前代码，对原日期范围内旧字段建立可用性屏障。范围外不受影响，后续有效观察可解除。同刻缺失与旧值仍为歧义，不解释为债券被删除。请求集合为unknown或partial时，所有最新值都保持不可用。`raw_observation` / `last_known_observation`只保存历史事实供审计。

字节SHA基于实际收到的原始字节。BOM及非规范编码不被静默剥除。预算逐chunk即时计入，即使后续大小、UTF-8、解析或校验失败也不退款。清理流的失败不能覆盖硬预算异常。超额拒绝整个切片，不以截断部分代替。

输出仅覆盖显式实例和有限字段，不证明全池、完整历史或真实首次公开时间。当前部分观察不能直接用于训练。模型接入必须另行冻结切片协议、原始捕获证明及新研究来源。任何未知、缺失或 partial 都须保留研究分母，不能靠删缺失记录取得更优成绩。

### 先验收观察覆盖，再接入成熟标签

第一阶段只回答：既有日常采集中的有限响应是否完整归档、在指定系统截止时刻能否验证其状态和原始字节。研究单位是实例内规范请求及其代码、原发行日和字段，不是全市场债券。每日先按生产调度实例登记清单。保留未触发、失败、缺manifest、空表、缺券、冲突和预算拒绝。不能从成功归档对象反向选择实例。

按来源分别记录实际请求数、成功/无数据/失败响应、归档成功/失败数、返回与缺失代码、字段状态、上下文冲突和有限范围可用数。分别报告独立调度预期的实例数、已证实请求数、请求总数是否已知和已证实范围的可用分母。缺manifest、step未执行或不可读时，请求总数保持未知。此时不能计零或称完整分母。未触发实例从独立调度预期清单识别。

只有请求总数可验证时才报告完整分母与可用分母之差。CTR无返回不能推断没有发行，未调度不能等同上游无数据。父批与二分叶批保留各自角色，不能相加成独立债券数。跨日重复观察也不能扩大独立事件分母。

当前CTR在发行后查询近期发行，CSS主要补齐资料，齐全后可能停止查询。这不是发行前候选池、全池持续修订记录或完整评级/条款公告版本。即使观察覆盖验收通过，也不能用这份目录补出历史h30方案、恢复过去预测时点的债券清单，或证明“未更正”。

第二阶段才构造新的成熟标签输入。发行事件键包含债券代码及原发行日，日期纠错另登记，不覆盖旧事件身份。同一事件多个提前期的训练总权重仍为1。最终票面只用定价来源的`TENDERFINALCOUPON`，定价日用`TENDERDATE`。

不从CTR的`ISSUERATE_REFERENCE`或公告日补造。标签只有在冻结截止前实际接收且持久化的最新最终票面有效、定价/发行日期上下文一致、有限请求集合可验证时才可纳入。成熟时点取相关接收、映射、内容及证明请求集合完整所依赖manifest上传时刻的最大值，且严格早于重训截止。若切片依赖多个声明实例的完整清单，所有依赖清单的可得时刻均须纳入。

未知清单没有可用的成熟时点。不能仅凭事后定价日或公告日认定标签当时可用。

最新null/empty/absent、缺券、失败、隔离、歧义或不可用状态不回退历史非空值。`raw_observation`和`last_known_observation`继续只供审计。当前读取器在声明的实例集合整体为unknown/partial时，使所有最新字段保持不可用。此时不能删除失败实例来取得完整覆盖。每次训练按截至当时的切片重新判定成熟集合，不把后来资料倒灌到旧训练月。所用系统观察时点是保守可用证据，真实首次公开时间保持未知。

### 方案条件与未来标签分开冻结

模型所用方案条件包括发行人、评级、期限、普通/次级、公私募及规模。它们须来自预测时点已登记的业务方案，或经独立验证的公开版本。每次修改创建新方案版本并保留实际登记时刻，不能用最终发行条件回填。当前观察目录本身不足以证明这些条件在发行前齐备。没有独立方案时只做覆盖研究，不生成可计入前向成绩的预测。

预测登记必须在未来标签出现前保存模型/源码、输入与日历哈希、实际预测时刻、方案版本、预测窗口及关联规则。没有已知债券代码时，不得事后挑选误差最小的同主体发行。此时先登记发行人、债型、期限/方式、计划区间及唯一或多笔匹配规则。

实际匹配与未匹配均进入台账。只有独立核实的事件身份可关联标签。无法唯一匹配单列，不静默丢弃。

查看新评价结果前，须冻结可执行协议。协议须明确上海时区h30的自然日/精确时差定义、同事件重复预测取样及方案变更处理。离线规则已在台账中固定，真实接入及前向评价协议仍待独立冻结。h30评价以真实定价日与事前预测时刻的间隔判定。

事后才能知道哪些登记符合h30，但不能据此重算或改写原预测。多个方案版本、滚动预测或提前期不得冒充独立债券，须分别披露登记数、匹配数、独立事件数和失败原因。被取消、条件改变、未发行或未成熟的登记继续保留其状态。

对照使用接入时独立冻结并验收的原Huber方法，先固定月度重训与包有效期规则。不能永久复用会到期的当前模型包，双方取得相同预测时点和方案信息，不用未来评级/条款给一方优势。先通过工程、真实输入及覆盖验收，再按PLAN既有至少3个定价月、30笔合格h30事件门槛积累前向证据。不得根据验收结果重选模型或放宽门槛。票面点预测、市场代理择时和真实融资收益继续分开报告，稳健中心不支持预期节约字段。
