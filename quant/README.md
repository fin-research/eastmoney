# 证券公司债融资择时模型研究报告

## 当前结论

当前选用历史迁移线性三分类模型，模型包为`778e5cd2116288b99576`。用户于2026年10月28日暂停进一步研究，授权发布目前同口径开发检验中表现最好的版本。发布验收进行中。

模型直接输出“尽快、等待、暂缓”及三档概率。建议取概率最大的类别，不设置快速下行触发器、反转规则或人工修改方向。

该版本属于探索性选用，尚未通过原研究的稳定性门槛。162个日期的成绩来自已反复观察的开发检验，不是最终参数包的新独立验证，也不能证明已解决快速下行时的误判。

旧票面模型`61492e3527e1ae367475`继续因数据质量问题暂停。其预测误差不作为本模型成绩。历史输入、原研究失败结果及人工结论保留。

## 业务问题

模型判断当前利率相对未来30个自然日的市场机会是否有利于发行。

|建议|含义|
|---|---|
|尽快|当前利率相对较低，模型倾向于尽快发行|
|等待|处于中间状态|
|暂缓|当前利率相对较高，模型倾向于未来可能降低|

当前对象是AAA证券公司债3年期行业收益率。行业二级收益率是融资市场代理，不是某家公司的真实发行票面。模型不输出发行日期、票面、融资节约金额、节约概率或贡献bp。工作台的实际融资统计来自独立业务数据。

## 数据与时间边界

数据由Data维护，本模型只读Neon。输入采用国债1、3、10年、国开债3、10年、AAA企业债3年及AAA证券公司债3年原始收益率。利率原始单位为百分比，差值乘100转换为bp。

每次发行建议记为T，输入观察日和可用日均必须严格早于T。线上读取此前90个自然日的小快照，并要求最新有效报价覆盖日历确认的前一报价工作日。共享市场和证券行业分别保留原始报价时钟。缺少所需历史、最新报价或日历年份时停止发布，不插值、不前值填充、不用零代替缺报。

共享输入是六条市场曲线各20个历史报价相对最新报价的变化，共120维；另加入目标曲线自身20维变化，合计140维。特征由既有注册构造器产生。标准化参数只用训练样本估计，训练常量列按原模型置零，不生成新的市场报价。

训练还使用企业债3年、国债3年、国开债3年和证券公司债5年四个辅助任务。证券行业3年任务的总训练权重为0.5，其余辅助任务共0.5；辅助任务先按不同历史日期均衡，再在同日期任务间分配权重。多任务日期不能当作独立市场事件数。

最终拟合包括1173个证券行业3年起点、全部任务合计13881行。所有起点、标签终点及30日窗口截止均早于2026年1月1日，2026年标签不回流训练。

## 标签与学习方法

对每个历史起点，计算未来30日历史窗口内有报价的工作日代理收益率相对当期收益率的平均差值A。正A表示后续利率平均更高、当期相对有利；负A表示后续平均更低。该标签评价整段窗口，不以未来最低点作为可实现的发行策略。

三个标签中心由训练期A学习，中间中心固定为0，另两个中心分别在负侧和正侧估计。训练样本按距离最近的中心形成暂缓、等待、尽快三类。判断边界由历史样本估计，不按人工规定的利率涨跌幅切档。

模型采用带L2惩罚的多项逻辑回归。设计矩阵包含140维标准化输入、截距及四个辅助任务身份项，以等待为参照类，共290个参数。惩罚系数为0.1；截距与任务项按原算法共同受惩罚。

本次发布只按既定算法进行一次最终参数拟合，不重新搜索候选或超参数。完整目标梯度给出的最优值差上界约为4.81×10⁻¹⁴，说明该凸目标的数值求解充分收敛；它不证明市场泛化能力。

## 开发检验结果

以下成绩来自2022年7月1日至2023年3月1日的162个历史起点，按原时间切分、成熟标签和原分母保留。开发成绩用于比较算法；最终发布权重用更多截至2025年末的成熟历史拟合，两者不是同一参数向量。

|指标|结果|
|---|---:|
|三分类正确率|45.68%|
|交叉熵|1.03705|
|Brier分数|0.62109|
|真实尽快样本|47|
|模型建议尽快|18|
|尽快判断正确／错误|10／8|
|尽快精确率|55.56%|
|尽快召回率|21.28%|
|被建议尽快样本的实际平均A|4.545bp|

18次尽快建议中有10次对应尽快标签，另8次没有；47个真实尽快样本中只识别出10个。4.545bp是该开发子集事后的标签均值，不是今日预期节约，也不是实际发行收益。

正确尽快样本集中在同一季度，最后一个开发折的交叉熵未优于比较方案。因此本版未满足原稳定性门槛。反复查看开发集会增加选模过拟合风险，不能把这些成绩称为封存测试或真实前向表现。

此前研究出现训练期几乎总能选中最低成本、开发期约8%的巨大落差，这属于明显的过拟合警讯。该旧路径选日指标不是本版三分类的45.68%，不能混用。当前发布没有改写旧结果，也没有据此宣称过拟合已解决。

## 线上运行与局限

Python与JavaScript对2026年10月28日真实T−1输入进行了全部140维特征、三档概率及业务字段一致性核验，最大数值误差约2.78×10⁻¹⁷。该项证明两端计算一致，不是新增效果评价。

线上Workflow冻结模型及只读输入，归档结果后经Dashboard发布函数原子写入。三档使用独立结构，保留同日运行ID和人工内容。默认接口拒绝未激活或暂停的模型身份，历史审计单独读取。

固定参数包有效至2026年12月31日，期间按既有交易日调度每日重新推理，不每日重训。报价不完整则失败关闭。跨入2027年前需核验新日历并发布相应参数包元数据，不能自动沿用未知年份日历。

当前模型依靠过去20个报价位置学习市场状态。它可能同时错过反弹或持续下行，历史迁移也可能将其他市场的关系带入证券行业。尚无独立证据支持长期稳定优势；用户授权的本次上线不改变这一研究结论。后续研究目前暂停，两融保持封存。
