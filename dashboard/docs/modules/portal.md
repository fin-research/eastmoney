# 门户

入口：`/`。公共规则见 [文档分流](../../AGENTS.md#context-routing)。仅在任务涉及本模块时读取。

## 页面设计

- 首页模块入口使用内在尺寸网格自动分列：卡片最小宽度 `280px`、最大宽度 `380px`，由 `auto-fit/minmax` 自适应换行并整体居中。不得依赖 `1280px`、`1080px` 等人工断点强制固定列数。

- 首页卡片内文字必须自然完整展示，不使用截断、单行省略或固定高度裁切。超长模块名允许换行。窄于最小卡片宽度时，单卡使用可用宽度。

- 五个业务入口之后增加同规格“管理”卡片，链接 `/management`。顶栏只保留统一的个人管理按钮，不展示管理图标。
