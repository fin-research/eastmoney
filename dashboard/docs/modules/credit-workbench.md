# 授信工作台

入口：`/credit-workbench`。公开材料检索与 AI 侧栏见 [授信助手](../CREDIT_ASSISTANT.md)，客户归属见 [客户与授信关联](clients.md)。

## 按日截面与存储

Worker 经 `HYPERDRIVE` 访问 Neon `credit` schema，migration 只放 `credit-migrations/`。

- `credit.institution` 保存单一当前状态：稳定 `id`、名称、机构性质、保密协议、银行经办机构、我司申请部门、我司经办人和债券投资偏好。修改直接更新该行，历史报告同样显示当前资料。
- `credit.metric(id,name,type)` 定义业务字段，`type` 为 `num/date/text`。`status` 是文字类型字段，供无到期日的机构保留底层审批状态。
- `credit.entry` 是唯一的运行时授信事实表，联合主键 `(report_date,field_id,institution_id)`。`v_num/v_date/v_text` 必须且只能填一项，并与 metric 类型一致。金额精度六位，额度非负，债券二级净余额可为负。保留来源的创建日期、创建人和修订时间，历史作者未知时留空。
- `credit.entry.verified` 是机构在精确报告日的人工定稿标记，同日所有字段一致，默认 false，未传入时保留当日标记，不跨日继承。
- `credit.entry_as_of(date,names)` 用 `DISTINCT ON (institution_id,field_id)` 按 `report_date DESC` 取截至所选日的最新值，再关联当前机构资料。零和空字符串是有效值，输入 NULL 表示未修改。金额取消填 0，文字清空填空字符串。首个记录日起任意自然日都可查询，默认上海时区今天。
- `credit.append_entry` 在同一授信写锁和事务内更新机构资料、比较归一后的业务值并写 entry。同日同字段直接更新，不加版本表。历史补录向后继承，后续明确字段覆盖补录。起止日期组合校验所有受影响的后续日期，撤销哨兵日期除外。
- `event` 枚举：`maintenance/new/renewal/increase/revocation`。同机构同日各字段的事件合并，优先级为撤销、首次新增、扩额，维护不降级已有事件。一次操作改多个字段也只有一条申请事件。到期仍由视图按期限生成，不写事件事实。
- 总额、四项额度、债券/其它说明、法透/其它人工已用、二级买卖净余额、起始日、到期日、额度描述和备注都是 metric/entry。历史台账债券已用只供对账，融资派生已用仍读融资台账。

### 历史修订与切换

- 跨业务日不删除也不直接更新 entry，普通 UPDATE/DELETE 由触发器拒绝。受控历史纠错用 `SET LOCAL credit.correct_history='on'` 按联合主键更新，主键、创建日期和创建人不可改，`updated_at` 不代替业务日期。
- 确需删除错误的历史行时，在数据库事务内持同一写锁，用精确联合主键删除。提交时校验受影响机构后续截面的期限。不按机构或日期批量删除。

```sql
BEGIN;
SELECT pg_advisory_xact_lock(hashtextextended('credit.excel_import',0));
SET LOCAL credit.correct_history='on';
DELETE FROM credit.entry
WHERE report_date='YYYY-MM-DD' AND field_id='字段ID' AND institution_id=机构ID;
COMMIT;
```

- 已写撤销哨兵（`1970-01-01`）的机构重新获批，必须登记真实的新到期日。过渡期旧入口只改审批状态而没有可恢复期限时明确回滚。一直没有到期日的未撤销机构仍按底层 `status` 处理。
- 长表切换分两步。默认 `pnpm credit:db:migrate` 只应用增量阶段：旧 Worker 的 diff 写入继续镜像，新 Worker 可读长表，写入暂返回 503，机构改名暂拒。
- 确认新 Worker 接管全部流量后，执行 `pnpm credit:db:migrate -- --finalize` 应用 `0019`。它在同一写锁等待旧事务完成，再关闭旧函数，把 diff 改名为只读 `legacy_diff` 并开放 entry 写入。此后默认命令继续应用后续 migration，旧 Worker 不能回滚到已收尾的数据库。当前截面不读 `legacy_diff`。

## 已用额度

金额以 PostgreSQL `numeric` 存储，汇总与元转亿元不转 `float8`。授信报表、详情联动和导入残差共用十进制运算，派生金额与二级余额按六位小数半入舍入。融资原始一级存续额保留元级精度，只在数字 DTO 边界转 number。

- 可用额度 `available = total - used`，使用率 `utilization_pct = used / total * 100`。`total=0` 时使用率为 `null`，页面显示缺失而不是 0%。
- 偏差：单机构派生已遵循零分母规则，汇总 `build-report.ts` 仍返回 0。目标是汇总也返回缺失，待修复。
- 收益凭证、同业拆借按截面日期调用 `financing.credit_usage_as_of(date)` 读存续本金，元转亿元，不在 entry 中重复存。
- 债券投资已用 = 一级发行存续额 + 登记的二级买卖净余额（亿元）。
  - 一级发行按静态客户关联读 `financing.bond_investors` 的实际投资人，由 `credit.bond_primary_usage_as_of(date)` 汇总。范围是已起息、未到期且未结清/关闭的认购金额。到期当日不计存续，历史不按当前债券状态回写。
  - 二级净余额正值为净买入，负值为净卖出，按业务日登记累计值。
- 总已用为五项有效值之和。客户未关联时，融资已用、总已用和可用保持缺失，不当作零。人工使用额和二级净余额的空值沿用合计按零处理。两融收益权转让归入其它。
- `status` 保留底层审批事实。视图先把 `expiry_date=1970-01-01` 识别为已撤销。有到期日时，报告日不晚于到期日为已获批，否则为申请中。无到期日沿用底层 `status`。起始日只展示，不参与状态覆盖，不回退上一期限。
- 一览表、汇总、周报、近期批复、日历、风险、周比较与图表统一排除所选日已撤销的主体。有效总额、已用/可用和使用率只统计所选日已获批机构。撤销前的历史截面不受后续哨兵影响。到期不改写底层 `status`。
- 原 Excel 的融资分项值只在导入时与融资台账比较并输出警告，不再存储。`reconcile-credit-bond-usage.mjs` 输出当前派生额和缺失关联。

## 接口与维护

写入校验同源、身份和 `credit.institution:update`，读取用 `credit.institution:read`，所有响应 `Cache-Control: no-store`。用户 ID 来自 `locals.user.auth0Id`。

- **读取**：`GET /api/credit?date=YYYY-MM-DD&month=YYYY-MM` 返回 `CreditDataset` 原始业务数据和日期上下文，`month` 默认所选日期所在月。非法日期/月 400，早于历史起点或无记录 404，连接异常 503。
  - 后端直接查询当前/对比截面、客户关联、用量、申请事实和事件日期截面。显式投影业务字段，不返回内部作者或审计 ID。当前/对比日期保留完整余额，其余日期只返回相关机构用量。Worker 不构造展示对象，也不拼装报表。
  - 浏览器和 CLI/Excel 核对适配器共用纯函数 `buildCreditReport(data)` 生成一览表、总额、使用率、周报与日历，不保留第二套公式。
- **AI 脱敏**：`GET /api/credit?view=masked&date=YYYY-MM-DD&institutionId=数字ID`，日期默认上海今天，ID 可省。响应为 `reportDate`、`amountUnit=亿元`、`institutions`，机构仅用字符串 `institution_id`，金额为十进制字符串，缺失为 `null`。不支持机构名称、日历或自由查询参数。
  - `credit.masked`（上海当日）与 `credit.masked_as_of(date)`（历史截面）由 `0023_credit_masked.sql` 定义：从 entry 白名单取最新字段，融资用量按 `institution_client.institution_id` 汇总，不查 `credit.institution` 或 `public.client`。返回额度、已用、剩余、使用率、期限、状态和报告日定稿标记，不返回机构资料、客户资料、自由文本或作者。日期继承、撤销排除、融资存续、缺关联和零分母口径与一览表一致，历史台账债券已用不进投影。
  - MCP `credit_report` 固定读此模式，见 [MCP](../MCP.md#授信)。授信新增/修改不进 AI 目录，网站维护接口按原权限使用。
- **明细**：`GET /api/credit?view=usage&date=...&institution=主体&type=bond_investment|yield_certificate|interbank_lending&offset=0` 返回该主体、该日、该品种的存续融资条目和合计。每页 100 条，offset 最大 100000。未关联时合计缺失，有关联且无存续条目时为 0。债券每行显示关联客户的实际认购额，同一债券可有多个客户条目。非法参数 400。
- **维护**：`PATCH /api/credit` 以 `operation`、`reportDate`、`institutionName` 和 `changes` 写入申请，`changes` 只传修改的字段。`viewDate` / `calendarMonth` 指定页面上下文，省略时沿用业务日及其月份。
  - 普通响应 `scope=institution`，只返回目标机构的原始数据替换集（空数组可删除失效数据）。浏览器替换该机构数据并响应式重算，保留筛选、排序、详情弹窗和日历月份，不再发 GET。历史起点或比较期变化时返回 `scope=context`，补齐事件和比较截面，当前日仍只含目标机构。保存途中切换日期/月时，用上下文和请求序号丢弃旧响应。
  - 维护不能变更总授信额度。后端在写锁内按业务日截面和六位金额精度核对。拒绝增加、减少、清零或首次登记总额，同值与省略可提交，分项额度仍可维护。
  - 续期、扩额、撤销、字段白名单、期限约束、事务和审计由后端验证，前端派生值不作写入依据。
  - 维护中延长已有实际到期日按续作记事，申请中转获批且未延长期限仍按新增记事，撤销哨兵不视为原期限。
  - 已登记金额传 NULL 不能清零，API 返回 400 并提示填 0。尚未登记的金额仍允许缺失。导入空白不覆盖原值，四项额度继续继承非零值时返回逐机构警告，dry-run 明确提示空白与零的区别。
- **新增机构**：`POST /api/credit` 用相同结构，至少含机构性质、状态、保密协议状态。主体重复 409。
- 一级发行存续额、收益凭证和拆借的原始用量由服务器提供，浏览器派生债券分项和总已用。债券 `secondaryUsedAmount` 可编辑，不得用 `usedAmount` 覆盖派生的债券合计。
- 周比较优先用七天前的截面，历史不足七天取更早的最近变更日。周报申请事件由 `entry.event` 决定，续期与扩额同日归为扩额。本周内续期的机构不再列到期。到期日由当前期限生成，被续期覆盖的旧期限不再提醒。首次历史导入作基准，不虚构当日新增批复。

## 导入

Excel 暂在本地导入，浏览器不解析也不上传源文件，源文件不提交 Git。

```sh
pnpm credit:import -- --file /absolute/path/授信周报.xlsx --date YYYY-MM-DD --dry-run
pnpm credit:import -- --file /absolute/path/授信周报.xlsx --date YYYY-MM-DD --user-id 'auth0|已核实的用户ID'
```

- dry-run 核对模板、机构数、一览表/周报口径和工作簿总额差异。先验证目标连接再写入。
- 实际导入返回 `addedDiffCount`：先建立主体和静态关联，再以原表债券真实值减去当日线上一级存续额登记二级买卖。金额比较与写入同一事务，非零债券真实值缺客户关联时整次回滚。
- 缺席机构不会被自动删除或撤销，撤销需明确状态。来源报表不覆盖已有的静态客户关联。
- 旧 Excel 固定列导入继续识别两融列并归入其它，不发生列偏移。
- 核对：`node --env-file=.env.database scripts/reconcile-credit-bond-usage.mjs --date YYYY-MM-DD --output /absolute/report.json`，输出一级存续、已登记二级净余额、有效已用和原台账参考值，缺关联保持 NULL。原台账参考值只用于对应历史日的对账。

## 页面与日历

四个侧栏入口为授信总览（`/credit-workbench`）、一览表（`/credit-workbench/ledger`）、日历、周报，复用 `WorkbenchShell` 和 `CreditView.svelte`，保留机构排序、筛选和周报版式。申请弹窗只办理新增、续期、扩额、撤销，机构详情由授信管理员编辑并显式保存为维护事件。`credit` 角色授予 `credit.institution:read` 和 `credit.institution:update`，无维护权限时字段不可交互且颜色不变。

- 顶栏“报告日”用左侧日历加右侧季度快捷项（如 26Q3）选择任意截面。“授信申请”办理申请事件，业务日默认报告日但可另选。详情维护固定使用全局报告日，所有修改和联动计算都按它保存。
- 维护详情中授信总额只读，总额变更通过授信申请。四项额度、法透/其它人工已用、债券二级买卖净余额可编辑，其余金额随输入即时计算。
  - 债券已用和可用也可编辑，分别按“已用 − 一级发行”“额度 − 可用 − 一级发行”反算二级买卖。
  - 一级发行、收益凭证、拆借已用是明细按钮，可查看存续条目。有融资数据读取权限时条目链到负债详情，返回时保留未保存字段。
- 总览页内标签“仪表盘”（默认）和“银行授信情况”（`?tab=bank-credit`），标签链接保留报告日。
  - 银行表按报告日已获批机构分政策性、国有、股份制、城/农商行、其它（外资、境外、民营）五类，未知性质独立保留。显示授信/已用/剩余及合计，亿元保留两位小数，任一参与机构额度或已用缺失时对应合计缺失。前十大按总授信额度降序、同额按机构名排序，缺失总额不排名，不合并独立授信主体。
  - 仪表盘依次为按银行类型、授信品种、Top10 三行，每行为额度、已用、使用率；随后是授信状态、到期期限直方图、使用率仪表盘及预警。金额与使用率只统计已获批机构，状态家数含申请中，统一排除撤销。到期直方图沿用期限分组，无到期日单独成组。
  - 品种额度只汇总非空的已登记额度：全未登记为缺失，明确登记 0 仍为 0。品种额度互相独立，不合成总额，其它没有独立额度。
  - 品种使用率的分子分母取该品种已登记额度的同一主体集合，已用缺失或额度合计为 0 时缺失。
  - 品种已用展示债券投资、收益凭证、法透、同业拆借，汇总全部有效主体，融资用量缺失保持缺失。
  - 银行类型汇总任一主体额度或已用缺失时保持缺失。Top10 各按自身指标降序，缺失不参与。使用率仪表盘用全部有效主体的完整额度与已用合计，缺失或零分母显示缺失，预警直接从当前 `buildCreditReport` 截面派生。单序列图和只有一个有效类别的状态图不显示图例。tooltip 显示各品种已登记/未登记家数、使用率同范围的额度与已用，以及未登记额度主体的非零已用。
- 一览表：
  - 机构性质在最左并按显示分类合并居中。国有银行/国有行、境外行及外资行/外资行共用显示分类，原始资料不变。先筛选再分组，性质排序控制组序，其余排序键在组内保持优先级。
  - 支持多列排序，默认先按机构性质既定顺序升序，再按总额度降序。点击表头依次添加升序、切换降序、移除，按添加顺序显示优先级，工具栏可清除或恢复默认。缺失值始终排末尾，键全相同时按主体名称稳定排序。周报保留原机构排序。
  - 整行点击或 Enter/Space 打开详情模态框。
  - 显示日期覆盖后的状态，只有无到期日时才可维护底层审批状态。申请中变获批按新增批复事件规则处理。
  - “导出 Excel”由浏览器生成单 sheet 工作簿（`src/lib/credit/export.ts`），版式沿用 2026 年 9 月 30 日的一览表，源模板不随应用分发。
  - 范围是点击时所选报告日全部未撤销机构（含申请中）。用默认分类和额度排序，不受搜索、风险筛选或临时排序影响。
  - 汇总只统计有效获批机构。任一有效机构缺失时对应合计留空，融资分项缺失留空，人工已用合计按空值为零。
  - 只输出数值，不写公式或条件格式。退休的两融及旧说明占位列隐藏且数据留空，文件名含报告日。
- 详情“定稿”开关随维护字段显式保存，任何报告日均可编辑。只有 3/31、6/30、9/30、12/31 且当日 `verified=true` 时在名称后显示绿色“定稿”。业务字段或文字维护不自动定稿，仅切换标记不产生申请或已用事件。当日无记录时用继承备注承载维护行。GET 与单机构 PATCH 用同一字段投影。
- 日历分额度、已用两组独立多选筛选（`MultiSelectFilter`），均默认“全部”，切月和切标签保留。额度选项：全部、新增、到期、续作/扩额、撤销。已用选项：全部和五个分项。两组分别筛选后合并展示。
  - 额度事件格式 `授信新增/授信到期/授信扩额/授信续作/授信撤销 · 总额亿元`。维护类型不生成申请事件，“续作/扩额”同时匹配续作与扩额，已被续作替换的旧到期日不再提醒。
  - 已用按业务日、机构、具体分项显示净变化，如 `同业拆借 · 增加1亿元`，不显示合计变动。融资部分读实际生效、到期、结清、关闭日期，人工部分读 entry 日期。
  - 债券一级发行与二级买卖分别显示：`债券投资——一级发行/二级买卖 · 增加/减少X亿元`，同日相互抵消也保留两条。每条已用事件带稳定 `itemType`，债券事件另带 `usageComponent=primary/secondary`，债券投资筛选同时覆盖二者，周比较的已用明细同样列出两个组成部分。
- 周报：
  - 指标卡变动样式见 [DESIGN](../../DESIGN.md)，无比较期显示“—”。快讯空态为“本周暂无”。
  - 含编号快讯、近六个月新增/续作/扩额批复（标题不显示时间范围）和按银行性质合并单元格的明细附表。分项额度与已用变化只在日历展示，不列入周报快讯。
  - “导出图片”下载一张含报告日、全部快讯、批复和授信明细的 PNG 长图，不分页。
