# 负债周报

入口：`/financing/liability-report?date=YYYY-MM-DD`。

## 生成与快照

- 只有用户点击“生成本期周报”才生成。浏览器并行调用：
  - Data 的 Choice CTR（可比券商发行）和分页 DM 券商债申报，经 Gateway `/data`；
  - 同源 `/financing/data/api` 的业务聚合 RPC 和 `public.edb` 原始市场观测只读视图，由 Dashboard 经 Hyperdrive 执行白名单 SQL 与 RLS。
- 进入页面或切换日期，只读该日已有的 R2 快照。没有快照时显示空状态并提示点击生成，不渲染六页空报告，不自动拉取 Neon、Choice 或 DM。
- `saveSnapshot` action 校验业务数据、来源、日期和大小，写入 R2 桶 `eastmoney` 的 `liability-report/yyyy-mm-dd.json`。快照含数据库数据、Choice CTR、DM 申报、缺失模块和口径。同日再次生成覆盖同一对象和 `liability_weekly_report_runs` 索引行。
- 生成成功后立即读取并重建新快照视图。软导航未取得新版本时自动整页重载。
- 历史月末融资指标读冻结汇总（`monthly_financing_metrics`），当前报告月份实时计算。
- 利率走势和国有行同业存单曲线只读 `public.edb` 白名单观测，在浏览器计算利差。读取层不用通用离群过滤，已确认的异常点由 Data 在写入端按完整源元组精确剔除。页面访问和生成都不请求 Choice EDB。
- Choice 或 DM 失败时，对应模块留空并记入缺失项。缺资产负债规模、利率序列、信用利差、同业发行或项目预计利率时，模块仍保留。生成完成后用全局系统消息写明缺口。
- 顶栏“报告日”日历选择器默认上海当天，页眉、统计日期和本周区间随报告日联动。

## 业务口径

- 余额快照是主动负债余额和结构的事实来源。明细余额与同日快照不勾稽时，模块仍保留，相关数值旁标注“数据缺失/待核对”。快照滞后于报告日时只提示日期缺口，不计算跨日差额。
- 页眉只展示报表日期和编制部门，不设数据口径条。滞后、勾稽和来源缺口只在生成后经全局系统消息提醒，正文不常驻。
- 未来 30 天与年内到期核心指标统计全量已安排负债，含尚未发行但已登记到期日的记录。未来 30 天到期明细排除同业拆借和浮动收益凭证，只列本金到期，不含债券独立付息现金流。
- “近期负债发行与到期动态”的本周，指报告日所在周周一至报告日已发生的发行、到期和付息事件。下周为下一自然周周一至周五。报告日之后的本周剩余日期不计入任一栏。
- 推进中的发行计划只在独立计划表展示，不计入事件或金额。收益凭证发行日优先取认购日。
- 可比券商发行和申报均取报告日所在周周一至报告日。发行定价限证券公司债、证券公司次级债和证券公司短期融资券。申报由 Data 固定证券业二级行业及指定申报品种读 DM，用上游返回的项目、发行人、状态、品种、金额和更新日。
- 可比券商年度发行按总额降序，证券公司债按原始期限拆为公募债和短期公司债，东方财富名称和合计标红。图表和表格统一删去公司制后缀，展示券商简称。
- 券商债与同期限国债按同一观测日配对，差值乘 100 后以 bp 展示。
- 融资额度按“净资本 60%”计算时，“获批日期与规则”固定展示“按上月末净资本×60%”，不因批复日期为空显示数据缺失。

## 版式

- 沿用安装包 HTML 模板（深蓝渐变页眉、A4 白色卡片、模板表格与状态色），也是项目组版式报告的打印基线，通则见 [DESIGN](../../DESIGN.md)。不套用融资工作台的通用页面 token 或共享指标卡样式。
- 主内容最大宽度 `1080px`。屏幕与打印共用六个 A4 页面 DOM，依次承载“第一+第二部分 / 第三 / 第四 / 第五 / 第六 / 第七”。页脚为公司名和“第 N 页 · 共 6 页”。
- 除这六个分页节点外，不加仅用于套宽度或背景的包装层。
- 打印只输出报告区，保持 `1080px × 1527px` 虚拟画布，以 `210mm / 1080px` 的固定 `zoom` 缩放到 A4，不触发窄纸宽重排，共享 shell 的顶栏、侧栏和提醒隐藏。
- 图表放在 `src/charts/financing/`，复用 `ChartHost` 和唯一 ECharts registry。`LiabilityReportActions.svelte` 只在本页工具栏按需加载。
- 五个监管指标复用市场点评仪表盘的细弧、指针、锚点和阴影，按监管预警与上限分段着色。柱体、饼图和进度色块只用纯色，不开 ECharts decal。图例、tooltip、单位、空状态、响应式和减少动效齐全。
- 公司融资余额趋势用面积图，横轴只显示年度刻度并标注年度节点。到期堆叠柱的最大合计标签用红色。
- 近一年公司债发行趋势拆分为短融、3年/5年公募债、3年/5年次级债。加权发行利率与柱体同色，只标最后一个有效值，图例不列利率系列。
- “本周券商债券发行定价”在左栏，“申报动态”紧随其后。申报较多时前半留左栏，续表从右栏顶部开始并标“（续表）”，两栏表头平齐。小屏恢复单栏。
- 表格按内容自动分配列宽，表头和长文本可换行，无横向滚动或固定最小表宽。额度进度图只占所在单元格的自适应短宽度。
