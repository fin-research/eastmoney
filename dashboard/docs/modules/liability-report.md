# 负债周报

入口：`/financing/liability-report`。公共规则见 [文档分流](../../AGENTS.md#context-routing)。仅在任务涉及本模块时读取。

## 业务不变量

- 负债周报未来 30 天与年内到期核心指标统计全量已安排负债并纳入尚未发行记录。仅未来 30 天到期明细排除同业拆借和浮动收益凭证，且不纳入独立付息现金流。

- 浏览器通过同源融资数据 API 的只读视图取得 `public.edb` 白名单观测。读取层不应用通用离群值过滤。券商债与同期限国债按同一观测日配对，差值乘 100 后以 bp 展示。周报生成不直接调用 Choice EDB。上游已确认的异常点由 Data 同步写入端按完整源元组精确剔除并从数据库删除。

- 可比券商发行和申报动态均取报告日所在周周一至报告日。发行通过统一 Data API 调用 Choice CTR，申报通过统一 Data API 固定证券业二级行业及指定申报品种访问 DM。任一外部源不可用时对应模块留空并写入缺失项，不回退安装包导入数据。

## 页面：Liability Weekly Report

- 负债周报视觉样式沿用安装包 HTML 模板（深蓝渐变页眉、A4 白色卡片、模板表格与状态色）。它同时是项目组版式报告的打印基线。主内容最大宽度为 `1080px`，屏幕与打印共用六个 A4 页面 DOM，依次承载“第一+第二部分 / 第三 / 第四 / 第五 / 第六 / 第七”，每页固定展示公司名和“第 N 页 · 共 6 页”页脚。打印范围只限报告区，保持 `1080px × 1527px` 虚拟画布，以 `210mm / 1080px` 的固定 `zoom` 等比缩放到 A4，不触发窄纸宽响应式重排。六张固定页面的分页节点属于必要结构，除此之外不增加仅用于套宽度或背景的包装层。不套用融资工作台的通用页面 token 或共享指标卡样式。
- 负债周报以余额快照作为主动负债余额和结构的事实来源。明细余额未与快照勾稽时，所有模块仍保留，相关数值旁明确标注“数据缺失/待核对”，不得用整块隐藏掩盖缺口。
- 报告首页页眉只展示生产数据对应的报表日期和编制部门，不设置独立数据口径条。用户生成周报后，才通过全局系统消息提醒滞后、勾稽及来源缺口。报告正文不常驻展示这些提示，不得用安装包静态值或本地 Excel 产物替代生产数据。明细余额只与同日余额快照勾稽。快照滞后于报告日时只提示快照日期缺口，不计算跨日差额。
- 周报全部业务图表统一使用 ECharts 组件，不得在页面或组件中手绘 SVG、Canvas、CSS 饼图或仪表盘。五个监管指标复用市场点评仪表盘的细弧、指针、锚点和阴影构造，再按监管预警与上限分段着色。柱体、饼图色块和进度色块只用纯色，禁止开启 ECharts decal 底纹。图例、tooltip、单位、空状态、响应式和减少动效必须完整。
- 公司融资余额趋势以余额快照为事实来源，余额使用面积图，横轴只显示年度刻度并标注年度节点。近一年公司债发行趋势固定拆分短融、3年/5年公募债、3年/5年次级债，各品种加权发行利率与柱体同色且只标注最后一个有效值，图例不重复列示利率系列。负债到期堆叠柱的最大合计标签使用红色。可比券商年度发行按总额降序，证券公司债按原始期限拆为公募债和短期公司债，堆积条形内部标注分项数值，并将东方财富名称和合计标红。
- “近期负债发行与到期动态”的“本周”只汇总报告日所在周周一至报告日已经发生的发行、到期和付息事件，“下周”取下一自然周周一至周五。不把推进中的发行计划计入事件或金额，融资计划只在独立计划表展示。收益凭证发行日优先取认购日。
- “本周券商债券发行定价”与“本周券商债券申报动态”按业务顺序组成连续双栏内容流：发行定价置于左栏，申报动态紧随其后。申报较多时，前半留在左栏，续表从右栏顶部开始并在标题标注“（续表）”。此时两栏顶部表头平齐。小屏恢复单栏顺序排布。
- 周报表格按内容自动分配列宽，表头和长文本可换行。不设横向滚动条或固定最小表宽。额度使用进度图只占用所在单元格的自适应短宽度。融资额度采用“净资本 60%”计算方式时，“获批日期与规则”固定展示“按上月末净资本×60%”，不因批复日期为空显示数据缺失。可比券商图表和表格统一删除公司制法律后缀，展示券商简称。
- 可比券商周表按所选报告日所在周的周一至报告日取数：发行定价限证券公司债、证券公司次级债和证券公司短期融资券。申报动态由统一 Data API 固定证券业二级行业及指定申报品种读取 DM，并使用上游返回的项目、发行人、状态、品种、金额和更新日。
- 未来 30 天和年内到期核心指标统计全量已安排负债，包含尚未发行但已登记到期日的记录。仅未来 30 天到期明细排除同业拆借和浮动收益凭证。明细只列负债本金到期，不把债券独立付息现金流伪装为“负债到期”。
- 周报只能由用户显式点击生成。浏览器直接并行调用统一数据服务的 Choice CTR、分页 DM 券商债券申报、同源 `/financing/data/api` 的业务聚合 RPC 和原始市场观测视图。Dashboard 通过 Hyperdrive 执行白名单 SQL 与 RLS。外部数据请求仍由浏览器调用 Gateway `/data`。

  历史月末融资指标读取冻结汇总，当前报告月份实时计算。利率走势只读 Neon `public.edb` 白名单观测，在浏览器计算利差。Data 私有定时入口与 Workflow 每日增量更新数据。页面访问和手动生成均不得请求 Choice EDB。`saveSnapshot` action 只校验返回数据并固化快照。Choice 或 DM 失败时对应模块留空并提示，不使用安装包导入数据回退。

  最终把可信数据库数据、Choice CTR、DM 申报、缺失模块和口径固化为现有 R2 桶 `eastmoney` 的 `liability-report/yyyy-mm-dd.json` 快照。同一日再次生成覆盖同一对象和数据库索引行。
- 国有行同业存单曲线直接读取 `public.edb` 已入库观测，不在周报读取层应用通用离群值过滤。上游已确认的异常点由 Data 同步写入端精确剔除并从数据库删除。
- 顶栏使用“报告日”日历选择器，默认上海时区当天。报告页眉、全部统计日期和本周区间均随报告日联动。进入页面或切换日期时只自动读取该日已有 R2 快照。

  没有快照时显示空状态并提示点击“生成本期周报”，不渲染六页空报告，不自动拉取 Neon、Choice 或 DM。生成成功后必须立即读取并重建新快照视图。软导航未取得服务端确认的新版本时，自动整页重载，不要求用户手动刷新。

  缺少资产负债规模、`public.edb` 利率序列、信用利差、同业发行或项目预计利率时，保留业务模块，并在生成完成后通过全局系统消息写明具体缺口。

## 调用与快照边界

报告图表统一放在 `src/charts/financing/`，复用 `ChartHost` 和唯一 ECharts registry。`LiabilityReportActions.svelte` 只在负债周报工具栏按需加载，首页、项目页不会预加载报表客户端。生成后按内容版本重新读取快照属于明确的报表刷新操作，普通表单仍禁止整页失效。

入口 `/financing/liability-report?date=YYYY-MM-DD`。`saveSnapshot` 验证业务数据、来源、日期和大小后写入原 R2 key，不迁移现有历史快照。图表与固定六页 A4 报告沿用原口径，打印时共享 shell 的顶栏、侧栏和提醒隐藏。
