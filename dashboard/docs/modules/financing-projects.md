# 融资项目

入口：`/financing/projects`、`/financing/projects/[id]`。SOP 模板与提醒见 [融资 SOP 与提醒](financing-sop.md)。

## 业务规则

- 项目独立于负债记录。创建、修改、删除都不读取、绑定或修改存续负债。
- 项目维护名称、融资品种、规模、负责人、状态、说明和单一“计划簿记”日期。创建时选择启用的 SOP，计划簿记日写入 `planned_issue_date`，是 SOP“计划发行当日”的相对日期锚点。
- 任务 `schedule_type` 分 `point`（时点，允许待安排）和 `period`（时段，须同时有启动日和完成日，启动不晚于完成）。历史任务默认按时点解释，不把旧版统一填入的项目起始日当作真实启动日。
- 项目起始日由最早任务启动日（时段）或计划时点推导，不晚于计划簿记日，任务增改后重算。
- 新建项目逐节点生成起止日期。修改计划簿记日时，SOP 时段的两端按相同自然日差平移，保留人工调整和区间长度。独立新增的任务不平移，零偏移的时点仍固定到计划簿记日。
- 项目详情可把已有任务切换为时段并维护起止日期。
- 删除项目在一个事务中同时删除任务及其提醒记录，重复删除按成功处理。
- 权限分三档：“项目管理”可维护项目和全部任务。“SOP 与提醒”维护模板、节点和提醒规则。“本人任务办理”只能更新 `assignee_id` 等于本人 `personId` 的任务状态，不能同时改负责人、截止日等字段。
- 业务“今天”按 `Asia/Shanghai`。
- mutation 成功后只合并服务端确认的实体，失败保留输入，不回滚到旧页面快照。

## 页面

- 甘特范围由上海时区当天、计划簿记日和节点日期决定，并扩展到完整月份。
- 月、季刻度、项目条、节点条和“今天”线共用同一百分比时间轴，不硬编码年月或位置。
- 时段显示区间条及起止日期，时点显示日期标记，待安排任务不伪造区间。项目条覆盖全部任务的起止日。
- 移动端优先用项目卡片，不强行压缩完整甘特图。

## 路由与表单

- 列表与详情在 `src/routes/financing/projects/` 和 `[id]/`。`/financing/projects/options` 只在表单打开时读取选项。
- 自动保存共用 `src/lib/financing/auto-save.ts`，创建和删除显式提交。普通 mutation 返回单一确认实体或删除 ID，就地合并，仅在需要时失效 `financing:reminders`，不重读全页。
- 新建项目用 Superforms 和 `src/lib/financing/project-form.ts` 的 Zod schema 做客户端与 named action 双重校验。名称、SOP、有效计划簿记日期必填，规模可空或为最多八位小数的非负亿元值。校验失败保留草稿并定位到错误字段。权限、SOP/负责人查询和写库只在服务端。其余表单用原生 SvelteKit forms。
