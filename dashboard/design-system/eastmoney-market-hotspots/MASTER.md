# 市场热点视图约定

本页继承 [全站 DESIGN](../../DESIGN.md)，不维护独立主题、字体或控件体系。入口、快照和证据契约以 [市场热点模块](../../docs/modules/market-hotspots.md) 为准。

## 视觉

- 使用冷灰浅色画布、白色摘要与详情面板、轻边框和全站低阴影。
- 保留多色词云与热度字号层次，文字使用全站系统字体。以较深的蓝、绿、橙、紫、红保证浅色背景上的可读性。
- 词云颜色直接使用品牌、成功、提醒、次级和错误等既有令牌。不通过发光、亮度滤镜或暗色描边强化文字。
- 摘要、解释与证据正文完整展示。正文使用 1rem，常规标签不小于 .875rem。日期与证据 ID 可用 .75rem。
- 标题、字重、6/8/10px 圆角以及按钮和表单基础类沿用全站约定，不加载外部字体。

## 布局与交互

- 宽屏保留画布及右侧详情布局。窄屏完整展示摘要，词云保留足够高度，必要时由工作台内容区纵向滚动。
- 范围设置与详情面板受视口约束，并避让工作台实际高度的顶栏。
- 主要控件不小于 44px。词语保留点击、Enter / Space 选择、可见聚焦和选中反馈。
- 尊重减少动效设置。选中和聚焦不改变文字边界与布局。

## 数据保护

- GET 只读取最近成功快照。只有用户明确操作生成按钮才发起 POST。
- 保留热度、证据范围、证据 ID、关联内容及原有解释，不因视觉改造重算或删减数据。
- 设计调整只影响热点业务视图，不修改门户和已定稿报告。
