# UI/UX 设计规范

本文件是全部页面的唯一 UI/UX 规范。新增或修改页面先复用既有组件与令牌，不在业务组件中另建平行样式体系。

## 视觉基础

- 风格：清晰克制的机构级研究终端。白色工作区、冷灰顶栏、深色侧栏、白色卡片、轻边框、低阴影。
- 门户保留已确认的暖白背景与彩色入口卡片。业务工作台用导航图标、分区标题和状态色增加层次，沿用亮色体系。
- 页面背景 `#f6f8fb`，主文字 `#172033`，次文字不浅于 `#667085`，品牌蓝 `#2f6fd6`，侧栏 `#202a38`。共享外壳只以品牌蓝作强调色。
- 全站只用系统无衬线字体栈。数字仅用 `font-variant-numeric: tabular-nums` 对齐，不为数字换字体。
- 工作台用 Maia 圆角：卡片 `16px`，按钮与输入框为胶囊。定稿报告保留 `6px / 8px / 10px` 令牌。
- 主操作、输入框和图标按钮的触控尺寸不小于 `44×44px`。

## 字号与字重

- 根字号 `16px`。业务组件用 `rem`，只取 `0.75 / 0.8125 / 0.875 / 1 / 1.125 / 1.25 / 1.5`。
- `0.75rem` 与 `0.8125rem` 只用于日期元数据、日历状态和紧凑表格。`0.875rem` 用于低优先级标签。
- 正文、图例、图表坐标和指标卡第三行用 `1rem`。常规文字不低于 `0.875rem`。模块标题从 `1.125rem` 起，页面标题从 `1.25rem` 起。
- `font-weight` 和图表 `fontWeight` 只用 `normal`、`bold`、`bolder`、`lighter`，不写数值字重。
- `normal` 用于正文，`bold` 用于标签、表头和模块标题，`bolder` 只用于页面标题和指标卡主值。字重不替代字号层级。
- 指标卡：左侧语义图标，右侧名称、主值、第三行辅助信息。第三行用卡片语义色，有符号变动数字按涨跌方向覆盖颜色。
- 授信周报的第三行用标准正文色，省略比较前缀，无变动显示“持平”。

## 页面层级与共享布局

- 一级称“板块/工作台”，对应门户入口。二级称“页面”，对应左侧导航。三级称“标签页”，只在 header。
- 各级都是真实链接，支持直接打开、刷新和前进后退。弹窗选项、表格筛选和年月切换属于局部控件。
- 工作台统一用 `WorkbenchShell`，业务 header 复用 `src/lib/workbench/PageHeader.svelte`。页面不另行覆盖标题样式。
- 一级与二级标题用系统字体、`1.25rem`、`bolder`、`--text-1`。品牌行 `0.875rem`。桌面顶栏基准高度 `64px`，内容换行时自然增高。
- `PageHeader` 的 `section/current` 提供层级链接，`tabs` 提供标签链接。两个及以上标签页才显示标签栏。单面页面不补“总览”占位标签。
- 选中标签用品牌蓝文字和底线，悬浮标签用淡冷灰底。标签栏贴合顶栏底边。窄屏标签栏独占一行并局部横向滚动。
- 通知管理用 `/management/messenger?tab=delivery` 与 `?tab=test`，无效或默认 tab 回到消息投递。市场点评用 `/market-briefing` 与 `/market-briefing/text`，标签链接保留报告日期。
- 旧 `/bond`、`/secondary-bond-pool`、`/financing-model` 入口用同一工作台装配，保留 URL 与查询参数。资金日报归档 HTML 原样返回，不注入应用布局。

## 内容与层级

- 标题区只放标题与导航。操作放在独立工具栏或内容底部。
- 页面不放解释性小字、口径扩写和功能提示，包括标题下说明、缓存策略和系统实现说明，也不移入 tooltip 或占位符。保留必要字段、业务数据、错误反馈和可访问名称。
- 指标口径变化不扩写标签，例如保持“已质押”。
- 工作台只呈现业务模块、数据基准日和业务状态。演示边界、数据来源和接入方案写入工程文档，不在 UI 放提示条、状态胶囊或页脚声明。
- 指标卡只保留名称、主值和有决策意义的变动。优先展示“较上周/昨日/月末”的变化量，数字按方向着色。
- 指标卡图标、图标颜色和浅色底与指标语义一致。同组卡片颜色不重复。
- 除市场点评外，模块标题不加 `01`、`02` 序号。
- 空状态、错误和加载文案直接说明状态与下一步。
- 写入、上传、删除、导出和后台刷新的系统反馈统一发布到全局消息层，页面内不设消息占位区。按钮可保留进行中状态。加载、空数据和整页读取失败属于内容状态。

## 色彩与图表

- 涨跌色服从用户配置：默认红涨绿跌，可切换。颜色之外保留正负号、方向文字或图形差异。
- 业务状态色独立于行情色：成功绿、危险红、主操作蓝。
- 柱、饼和分类图用与 `fin-ops` 一致的多色序列：`#2f6fed`、`#16a394`、`#6941c6`、`#f79009`、`#d92d20`、`#0ba5ec`、`#6172f3`、`#12b76a`。
- 图表提供图例、tooltip 和 ARIA 描述，不只用颜色区分类别。tooltip 限制在图表内，长名称换行。
- 图形服务于数据含义，不用无业务含义的渐变或装饰动画。主要动画不超过 `300ms`，并尊重 `prefers-reduced-motion`。
- 容器有稳定高度并随尺寸重绘，避免标签裁切、重叠和无效留白。
- 业务数据图表经 `ChartHost`（`src/components/ChartHost.svelte`）用 ECharts 绘制，不用手写 SVG、Canvas 或 CSS 宽度条模拟。SVG 只用于图标和无数据含义的插图。
- 同类图表复用 `src/charts/` 的配置构造：配色、字号、网格、轴线、图例、tooltip、ARIA、动画和重绘。页面只传业务数据与可访问描述，不内联 ECharts option。
- 横向比较图用圆角横向柱和右侧数值标签。一般品种比较可用浅色轨道，正负因子贡献图保持透明底，无网格线。
- 趋势与期限曲线用相同轴线、虚线网格、线宽和 tooltip。业务阈值用 ECharts `markLine`。

## 布局与组件

- 桌面内容最大宽度 `2100px` 并居中。同一行卡片上下边线对齐，表格和图表在模块内处理溢出。
- 移动端保持模块 DOM 顺序，按单列排列，不用折叠、分页或重排改变阅读顺序。
- 表格：表头清晰、行高一致、数值右对齐、名称左对齐。移动端只在表格区域横向滚动。
- 弹窗在视口内居中并限制最大高度，内容在弹窗内部滚动。危险操作二次确认。
- 可用的按钮、按钮式链接和控件显示手形光标，禁用控件不显示。悬浮反馈沿用各组件变体。
- 原生表单有可访问名称，图标按钮有 `aria-label`，键盘焦点清晰可见。
- 指标卡、面板、模块标题、状态标签、表格控制和图表容器优先复用共享组件与样式类。同一信息结构不在不同标签页建平行组件，需要变体时用 props、modifier class 或共享 renderer 扩展。
- 工作台各标签页共用页面内边距、卡片边框、圆角、阴影、标题和表格规则。工作台令牌映射全局设计令牌，不另立品牌色、背景色、正文色或圆角体系。

### 共享组件归属

复用顺序：先搜索现有组件和样式；能直接用就直接用；结构相同但有差异时扩展 props 或 modifier；确认无可复用基础才新增共享组件。

- `src/components/ModuleCard.svelte`：普通业务模块卡片，兼容 `.tr-panel`。统一白色表面、轻边框、工作台 `16px` / 报告 `10px` 圆角、低阴影和内边距。这些页面的普通模块直接复用：总览、交易管理、授信管理、研究辅助、流程中心、二级池、融资择时。页面不重复声明卡片表面。
- 市场点评的高密度报告面板保留 `.dashboard-panel` 与 `.panel-heading`，映射同一组全局令牌，不另设视觉参数。
- `src/components/MetricCard.svelte`：市场点评、交易研究普通快照、二级池和融资择时的唯一指标卡。名称、主值、单位、变动、图标容器、语义色、底色、边框和换行由它负责。业务页只配置 `tone`、`iconPosition`、`compact` 与数据，不再定义 `.core-card`、`.metric-card`、`.ledger-metric` 等同义结构。
- 研究辅助经济数据矩阵的卡片含日期和 ECharts 趋势图，用专用 `src/lib/trading-research/EconomicIndicatorCard.svelte`，不替代普通指标卡。
- `src/lib/trading-research/` 下的 `SectionHeading`、`PanelHeading`、`Badge` 分别负责模块标题、卡片小标题和状态标签，所有工作台标签页及融资择时复用。`PanelHeading` 用左侧品牌色短线、`1.125rem` 粗体标题和下方控件行，桌面筛选框一字排开。
- `ChartHost` 负责图表生命周期、容器尺寸和可访问名称。业务模块不另建图表容器。
- 共享组件样式由组件或其唯一样式文件维护。业务页 CSS 只负责网格、位置和业务布局变体，不覆盖共享组件的字号、颜色、边框、圆角或阴影。
- 市场点评桌面鼠标操作区用 `32px` 控件，由 `.page-shell` 的 `--report-control-size` 统一。`900px` 以下或粗指针设备恢复 `44px`。这是高密度报告的唯一尺寸例外。

### 工作台精修与报告隔离

- 所有工作台的 Header 与侧边导航外观一致。导航用深灰底、蓝灰选中底色、品牌蓝短竖线、白色选中标签、12px 圆角、48px 行高和相同线性图标，不按业务切换颜色。
- 侧栏样式由 `src/lib/trading-research/workbench.css` 唯一维护。工作台内容圆角与控件规则只作用于 `.tr-workspace`。
- `layoutReport`、`integrated` 和 `visualVariant="report"` 视图不启用工作台精修。授信周报显式用 `visualVariant="report"`。
- 市场点评、资金日报、负债周报、二级池周报和融资择时报告沿用各自版式。普通页面改造不得通过全局主题或共享卡片基础样式影响定稿报告。
- `report-controls.css` 只覆盖 `.page-shell`、`.layout-report` 和非工作台 `.tr-shell` 下的控件，不扩散 Maia 样式到报告。
- 顶栏按内容换行。窄屏保留个人入口和业务操作。关闭的移动导航不可获得键盘焦点。固定新增按钮所在页面预留底部空间。
- 普通指标网格用内容可承受的最小宽度，不把三张窄卡塞进窄屏。金额与单位分别传入 `MetricCard`。缺失值不当作零。
- 输入值正常字重，标签强调。按钮和输入框的颜色、边框由 Maia 基础组件负责，旧页面 CSS 不覆盖主按钮配色。提问框是组合控件，只有一个外框和一个聚焦指示。
- 普通融资表格用内容驱动列宽，日期完整显示，必要时在可聚焦的表格区域内横向滚动。
- 融资仪表盘待办统一放顶栏提醒面板，日历占满一行，周末切换在日历标题控件区。发行试算只呈现已实现的额度校验。
- 市场热点用浅色画布和白色传导图面板，映射全站令牌。细则见[热点视图](docs/modules/market-hotspots.md#视图)。

## 门户与工作台响应式

- 路由组件的常驻全局样式不写 `html/body` 背景、最小宽度或滚动锁。全屏页面由自身根容器承载，避免导航后污染其他页面。
- 交易研究工作台用可深链的 path：`/trading-research` 为总览，其余为 `/trading-research/<module>`，含市场热点与政策跟踪。首页只保留工作台入口。不用 `?view=` 保存二级页面状态。
- 工作台是 App 型框架，全宽顶栏在侧栏与内容区上方。桌面用 `PanelLeft` / `Sidebar` 线性图标折叠侧栏，移动端用菜单图标开抽屉。侧栏无独立 `tr-brand`，顶栏无单独的门户返回按钮。
- 顶栏当前位置用“交易研究工作台 / 当前模块”层级导航。其上方的“东方财富证券 · 资金管理部”是紧凑门户入口。
- 该路由存续期间 `html/body` 锁定视口高度且不滚动，唯一纵向业务滚动容器为 `.tr-workspace`。顶栏和侧栏始终在视口内。
- 授信周报、二级债券池运营周报和融资择时模型报告统一视为版式报告。屏幕报告区最大宽度 `1080px`。
- 打印只输出报告区：A4 portrait、零页边距、`210mm / 1080px` 固定 `zoom`，显式恢复桌面栅格，不因打印视口变窄重排。
- `#tr-workbench-main` 直接用语义化 `<main>` 作为二级池、融资择时报告画布。报告组件不再加仅用于套宽度或背景的包装层，独立路由只有一个报告主容器。
- 负债周报用同一打印基线，六张固定 A4 页面可保留必要的分页 DOM。
- 版式报告内所有表格使用内容驱动的自适应列宽，不设固定或最小表宽。长文本完整换行，表格及容器无滚动条且不溢出报告区。
- 页面使用 `portal` 时，保留位置稳定的组件根节点，只移动根节点内的操作区。授信助手组件的挂载、切换、卸载和迟到响应由 DOM 回归测试覆盖。

### 全站 AI 侧栏

- 根 layout 在所有页面右下角固定紧凑 AI 标签。打开后桌面侧栏占据布局宽度并压缩页面，移动端占满视口。
- 侧栏有通用对话和业务任务两个标签。对话支持按用户隔离的本机历史、新对话、工具选择、Ask/Act 模式、写操作确认、流式正文、停止与复制。
- 任务发起后自动进入详情，在固定位置逐条替换模型公开 summary。完整记录折叠展开，终态结果在其下方。
- 完成后面板保持打开并发布全局完成通知。任务列表保留当前前端会话内的状态与结果。面板支持关闭、Escape、焦点恢复和减少动效。
- 保留的 CreditAgent 会话由 `CreditActivityView` 只显示处理状态，模型 summary 进入统一 AI 面板。

### 交易流程图

交易流程的数据与交互见 [交易研究工作台](docs/TRADING_RESEARCH_WORKBENCH.md#交易流程)。视觉验收基准是用户提供的参考图。

- 用 Svelte Flow 的节点与连线表达业务关系，不用模块卡片包裹品种或共通步骤。沿用全局令牌与系统字体，节点内无编辑或拖动按钮。此类可编辑流程图不属于 ECharts 数值图表。
- 顶部品种分类不是节点、不连线，保留浅色品种框，文字居中，折叠控件在右侧。桌面三条流程的横文字标签吸附右侧并纵向排列。手机标签在画布顶部横排，点击展开或折叠。
- 询价在各品种下方，先于共通交易要素。多个前序指向同一节点时，共通节点居中。同级分支子节点以品种色浅边框归组。
- 主干从底部中心出线、顶部中心入线。分支首条连线用左右侧出口，同一目标的入边在同一水平线汇合。
- 节点最大宽度 `460px`，列内居中，垂直间隔至少 `76px`。
- 左侧时间轴全长着色，实时水平线位于节点下层。
- 未完成节点白底。完成后加深品种色并保留图标。分支须全部后代任务完成才着色。询价不参与完成状态。
- 节点、连线和组框同步滑入淡入、收回淡出，减少动效时直接切换。
- 编辑模式的控件放全局 header。不用缩放把全部节点压进一屏。

## 导出与验收

- 报告导出为 3 倍像素密度 PNG，只含报告正文，不含工具栏、弹窗和临时状态。导出不改变滚动位置，完成后恢复页面状态。
- UI 改动先做本地快速检查和相关测试。视觉变化按 [TESTING](docs/TESTING.md) 在本地审阅受影响页，合并队列执行完整构建与截图比较。

## 融资与管理模块复用

- 融资工作台和管理中心复用 `WorkbenchShell`、`MetricCard`、`ModuleCard`、`PanelHeading`，图表经 `ChartHost` 共用 registry。全站只挂载一个 `GlobalMessages`（`src/lib/GlobalMessages.svelte`）。
- 融资业务 CSS 限定 `.financing-scope` 并映射全局令牌，不另设 Tailwind/shadcn-svelte 主题或全局 html/body 规则。样式带完整业务子选择器，项目汇总类用业务前缀，防止报告网格规则泄漏。
- 六页负债周报保留专用报告版式。含贴边表格或时间轴的模块用 `ModuleCard padding="none"`。
- 融资待办用顶栏“查看提醒”下拉面板，不占正文高度。窄屏保留个人入口、提醒和周报操作，抽屉顶部跟随顶栏实际高度。项目和 SOP 详情在正文展示实体名称。
- 公共交互：可访问 label、`44px` 控件、保留失败输入、模态框内滚动、危险操作确认、减少动效。模块行为细则见对应模块文档。
- 首页以与业务入口同级的卡片展示“管理”。共享 `AuthMenu`（`src/lib/AuthMenu.svelte`）只显示“用户图标 姓名 / 部门”，进入 `/management/me`，部门缺失显示“未填写部门”。
- 姓名/部门入口在所有页头用 `1rem`，排在业务操作之后并靠最右，窄屏换行后仍右对齐。门户页头“资金管理部”标题用 `1.25rem`。
- 无权限的页面入口和写控件不呈现，不用禁用按钮替代。通知设置复用 `ModuleCard`、`Input`、`Checkbox`、`Button` 和 `PanelHeading`。管理导航结构见 [管理](docs/modules/management.md)。

## shadcn-svelte Maia 基础组件

- `components.json` 固定 `style: maia` 与 Lucide。`src/lib/components/ui/` 保存官方 Maia registry 生成的组件。品牌色与系统字体由 `app.css` 的语义令牌映射。不引入其他 UI 框架，不用平行 CSS 模拟基础组件。
- 按钮、输入框、选择器、复选框、标签、卡片和表格用本地 shadcn 组件。变体用 `tailwind-variants`，类名合并用 `clsx` / `tailwind-merge`，图标用 `@lucide/svelte`。交互用 Svelte 5 Runes，动画用 CSS / Svelte transition。
- `--border` 是 shadcn 边框色，`--muted` 是次级表面。业务文本用 `--text-muted`，业务线条用 `--border-color` / `--line`。图表线条读 `--chart-line-color` / `--chart-grid-color`，不用控件令牌。
- 弹窗用 `src/lib/components/Modal.svelte` 封装的 Bits Dialog，保留取消拦截、内部滚动和关闭后焦点恢复。浮层、多选和页内选项卡用 Bits Popover / Checkbox / Tabs。Sonner 沿用消息去重与悬停暂停。
- 简单表单用 SvelteKit named actions / enhance，复杂表单用 Superforms 与共享 Zod schema。数据维护用 TanStack Table，图表用 ECharts / `ChartHost`。服务端加载与增量失效由 SvelteKit 负责，不引入平行状态缓存。
- DOM 与浏览器回归检查草稿、多选、弹窗和消息行为。
