# Choice 原生协议

Choice 会话由 `ChoiceSession` Durable Object 持有，直连厂商服务器。
Data 的六个函数及公开表格契约不变。
办公室 C++ RPC 已于 2026-11-03 退役。

## 会话和协议

每个授权账号由一个对象持有会话。
对象串行处理查询，按需登录，不维持心跳。
登录令牌连同轮换后的激活凭据存入对象存储。
登录失败或网络超时不会自动重发数据查询。
登录失败后冷却 60 秒再重试。

CSD、CSS、CTR、EDB 和交易日使用厂商 TCP 帧。
额度与权限等辅助请求使用厂商 HTTPS 接口。
发送头为 14 字节，接收头为 13 字节。
响应支持 gzip 和厂商类型化表格。
厂商 SDK、服务器清单、真实数据和凭据不进入公开仓库。

## 配置与恢复

`CHOICE_SESSION` 是本 Worker 的私有对象绑定。
`CHOICE_CREDENTIALS` 和 `CHOICE_SERVERS` 必须配置为 Worker Secrets。
不得把它们写入 Wrangler vars、日志或测试夹具。

`CHOICE_SERVERS` 提供 3、6、19、20 类服务地址。
各地址包含 `hostname` 和 `port`。
`statisticsOrigin` 是厂商权限服务的 HTTPS origin。
从当前私有 SDK 清单确认地址，不复制历史 IP。

凭据支持 `auto` 和 `password` 两种模式。
自动模式包含 `uid`、`ctoken`、`utoken`。
密码模式包含 `account`、`password`。
两种模式均须明确提供 `deviceId` 和 `deviceModel`。
迁移预激活凭据时保留原设备标识。
密码登录已于 2026-11-03 在用户授权下实测通过。

对象保存登录后轮换的激活凭据。
对象将这些凭据与账号、设备指纹绑定。
更换身份时拒绝复用旧会话。
管理员可经私有对象绑定调用 `reset()`。
该操作清理令牌、激活凭据和持久状态。
公网 HTTP 没有恢复入口。

## 按需登录与令牌有效期

对象收到查询才登录，令牌存入对象存储，对象被回收后仍可复用。
令牌满 20 分钟后，下一次查询重新登录，并复用已轮换的激活凭据。
实现不连接心跳服务器，没有定时唤醒，也不持有 socket。
令牌失效或被踢号时，查询以上游错误码失败，直到令牌到期或管理员调用 `reset()`。
令牌到期后对象会自动重新登录，不再因被踢而暂停。
该账号不得同时被桌面客户端或本地脚本登录，否则双方可能互相挤下线。
厂商 SDK 在同账号已有会话时返回 `login count up to limit`。原生登录在已有会话时的行为尚未测试。
每次登录都会轮换激活凭据，自动模式下登录应答丢失会使账号需要 `reset()` 并重新预激活。

2026-11-03 实测（密码登录，单会话，Node 直连）：

| 项目 | 结果 |
| --- | --- |
| 心跳服务器空闲 15 秒、30 秒 | 心跳正常回复 |
| 心跳服务器空闲 60 秒及以上 | 服务器已先断开，45 至 58 秒内关闭 |
| 登录后不注册心跳，第 0、1、3、10、30 分钟查交易日历 | 全部成功 |
| 本地 workerd 运行真实 `ChoiceSession`，首次查交易日历（含登录），再查一次 | 均成功，第二次不登录 |
| 同一环境各发最小请求：CSS、CSD、EDB（类型 6 服务器和额度 HTTPS）、CTR（类型 20）、统计 | 均成功 |

令牌有效期的上界尚未测出，实现取 20 分钟，低于已测的 30 分钟。
Choice 日期不补零（如 `2026/11/2`），解码须补零并校验真实日期。
实测使用密码登录，只请求了类型 3 服务器的交易日历。
自动模式重新登录没有在无心跳下验证。
统计与额度 HTTPS 接口的函数名用 `EM_CSS`、`EM_EDB` 等，传 `CSS` 返回 4008。Workers 不支持 `redirect: 'error'`，这两个请求用 `manual`，重定向按失败处理。
厂商计量可能依赖已删除的心跳注册，须在发布前核对。

## 费用

不持有 socket，对象只在查询期间计 duration。
没有定时唤醒，空闲时不产生请求和 duration。
登录次数约为每 20 分钟一次，且仅在有查询时发生。
实际查询和存储另计。

Workers Paid 最低套餐费用为每月 5 美元。
其他服务共享额度，不能据此承诺账单为零。

费用依据：[Cloudflare DO 定价](https://developers.cloudflare.com/durable-objects/platform/pricing/)。
连接行为依据：[TCP sockets](https://developers.cloudflare.com/workers/runtime-apis/tcp-sockets/)。
部署前须重新查询价格及账号剩余额度。

## 已恢复的兼容路径

新版 EDB 使用 `$-edb`，旧版 `E` 加七位数字使用 `$-bond`。
新版 `IsPublishDate=1,FixDate=0` 先查询 `$-EDBDATE`。
返回的 `PUBLISHDATE` 按代码和观测日期关联。
旧版编码按 SDK 行为忽略 `IsPublishDate`。
EDB 保留授权、查询、再次授权和计数确认的执行顺序。
计数确认失败时不返回数据。

CSD 使用当前 SDK 的 `em_csd_2` 路径。
查询交易日后，按代码和日期补齐空单元格。
CSD 和 CSS 按厂商百分数元数据及证券类型处理数值。
元数据缓存一小时，不推测证券类型或百分数标志。
CTR 保留字段选择和未知字段回退行为。
协议错误保留数值错误码，不回显厂商正文。

每个原生响应上限为 16 MiB。
解码和输出分别限制为 100,000 行及 1,000,000 单元格。
超限或协议不明确时拒绝返回数据。

## 明确的兼容限制

当前 CSD 支持日频、`FillData=0` 和交易市场日历。
非日频、`Market=0/1`、填充前值尚未实现。
EDB 不支持 `FixDate=1` 或最新值转换。
CTR 不支持多表响应。
日期宏、证券别名和分组转换尚未恢复。
这些限制须在生产切换前逐项核对调用方。

## 辅助请求与本地限流

CSD 的交易日查询单独计入 TRADEDATES 限流。
证券类型和百分数元数据请求计入 CTR 限流。
EDB 的授权、发布时间和计数请求均计入 EDB 限流。
上游真实数据额度仍由厂商服务控制。
本地触限后不重试、不更换账号或函数。

## 离线证据边界

测试使用人工合成响应，不使用真实业务数据。
合成表格已通过 SDK 纯解码函数对照。
完整链路回放覆盖百分数处理、日期补齐及 EDB 发布时间。
会话测试覆盖轮换凭据、令牌复用、到期重新登录和重置。
测试也覆盖计数失败时禁止返回数据。
离线测试未执行真实登录、取数或部署。真实登录和交易日历实测见上文。

会话测试替换了 Cloudflare 类、对象存储和网络。
传输测试替换了 socket，编解码使用实际实现。
这些测试不验证真实 workerd 对象生命周期。
dry-run 只验证构建，不验证厂商网络或真实账号。
